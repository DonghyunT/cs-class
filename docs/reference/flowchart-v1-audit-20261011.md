## 후속 구현 계획 — 2026-10-11

사용자의 후속 구현 요청에 따라 아래 순서로 작업을 나눴습니다. 공유 저장 계약·실행기·AI 응답·CSS는 주 에이전트가 통합하고 독립 파일만 담당을 나눴습니다.

Ponytail full을 적용해 기존 편집기·검증기·useWork를 재사용했고 새 의존성이나 작품 저장 스키마는 추가하지 않았습니다. 독립 리뷰에서 빠른 시작 문제를 바꿔도 이전 조건/계획 후보가 남는 문제를 찾아 재현 검사 후 수정했습니다. 탭 전환 자체는 후보를 보존하며 새 빠른 시작 선택만 후보를 비웁니다. 저장된 작품은 채택 전 유지합니다.

반복 검사에서 실제 드래그의 `effectAllowed=move`와 도착점 `dropEffect=copy` 불일치, 390px 고정 퍼즐의 불필요한 좌우 여백을 확인해 제품을 수정했습니다. 아직 렌더링되지 않은 목록을 읽던 검사 두 곳은 실제 보관함/기호 준비를 기다리도록 고쳤습니다. 글자 크기·허용오차·타임아웃을 낮추거나 늘려 통과시키지 않았습니다. 최종 실행의 날짜·환경·결과·화면·기록 복원은 HANDOFF의 최신 절을 따릅니다.

첫 통합 실행에서 320px의 시작 기호 위치 계산이 새 SVG 원점을 반영하지 않음을 찾아 보완했습니다. 구형 빈칸 문구·타원 선택자는 현재 힌트와 실제 기호 도형을 검사하도록 갱신했습니다. 교사 체험 초기화 때는 준비 중인 iframe의 이미지 요청이 취소되어 늦은 decode 오류가 발생하는 것을 trace로 확인했습니다. 폐기된 프레임의 비동기 완료/오류 송신을 취소하며 활성 프레임의 실제 이미지 실패는 계속 안내합니다. 준비된 일곱 수업 화면 검사와 준비 중 빠른 초기화 검사를 구분했습니다.

## 먼저 고칠 기능 문제

### 1. 예시 공방의 버튼이 기존 자유 작품을 덮어씀

- **현재:** `공방 기호를 자유 캔버스에 복사`가 기존 자유 작품의 기호·화살표를 `guideGraph(4)`로 바로 교체합니다. 교체 확인도 없고 해당 버튼은 저장/AI 잠금도 따르지 않습니다. 다시 생성된 자유 공방의 undo 이력은 비어 있습니다.
- **V1:** 해당 위치의 버튼은 `5단계 나만의 공방`으로 이동합니다.
- **영향:** 학생이 예시를 본 뒤 이동하려다가 미제출 자유 작품을 잃을 수 있습니다. 이전 제출본 보존과 현재 초안 보존은 별개의 문제입니다.
- **확인:** 코드로 확정. 현재 `flowchart.tsx:38`, `flowchart-studio.tsx:38`; V1 `index.html:2343`.
- **제안:** 기본 동작을 이동으로 복원하고, 예시 복사는 별도 조작으로 제공합니다. 기존 작품이 있으면 교체 내용을 확인하고 되돌릴 수 있게 해야 합니다.

### 2. 자유 공방에서 이름·문자 비밀번호를 입력할 수 없음

- **현재:** 자유 작품에는 문자열 입력 노드 설정이 없어서 모든 입력을 유한 숫자로 제한합니다.
- **V1:** 숫자로 해석되지 않는 입력은 문자열로 받습니다.
- **재현 확인:** 순수 실행기의 `시작 → 이름 입력 → 이름 출력 → 종료`에서 `테스트` 입력 시 `유한한 숫자를 입력해 주세요.` 오류로 멈췄습니다.
- **근거:** 현재 `src/lib/classroom/review/flow-runner.mjs:26`, `flowchart-studio.tsx:119`; V1 `lab-flowchart.js:3993`.
- **제안:** 자유 작품의 숫자/문자 입력·출력·비교를 함께 점검해 V1 의미를 복원합니다. 기존 숫자 퍼즐과 비밀번호 퍼즐의 명시적 입력 계약은 보존해야 합니다.

### 3. 기호의 여러 줄·긴 문구가 화면과 PNG에서 누락됨

- **현재:** 문구를 14자 단위로 나눈 뒤 자유 공방은 두 항목만 그립니다. 줄바꿈 문자도 항목으로 계산합니다. 기호 크기는 고정이며 PNG는 이 SVG를 복제합니다.
- **재현 확인:** `첫째 줄\n둘째 줄`은 `첫째 줄`과 빈 줄로 그려져 둘째 줄이 사라집니다. 짧은 문구라 말줄임표도 표시되지 않습니다. 입력/저장 데이터의 삭제가 아니라 **표시·내보내기 누락**입니다.
- **V1:** 일반 기호는 내용에 따라 크기가 늘어나는 DOM을 사용합니다.
- **근거:** 현재 `flow-diagram.tsx:22,206,224`, `flowchart-export.ts:12`; V1 `lab-flowchart.js:2442,2460`.
- **제안:** 실제 줄바꿈과 긴 문구를 보존해 기호 크기·포트를 계산하고, 내보내기에서도 전체 내용을 보장합니다.

### 4. 새 연결이 기존 연결을 설명 없이 교체함

- **현재:** 같은 출발 기호+갈래의 기존 선을 모두 제거한 뒤 새 선을 넣습니다. 판단 기호의 상단은 ‘연결 받기’라고 표시하면서 출발 포트로도 쓰이고 ‘예’ 갈래로 해석됩니다.
- **V1:** 상단 `in`, 하단 `yes`, 오른쪽 `no`를 구분하고 같은 포트 쌍의 중복만 막습니다.
- **재현 경로:** 판단 기호 하단→A 연결 후 같은 기호 상단→B 연결 시 A로 가던 예 연결이 사라집니다. 사용자 작품에서는 실행하지 않고 콜백/필터 경로로 확인했습니다.
- **근거:** 현재 `flowchart-studio.tsx:68`, `flow-diagram.tsx:31,144`; V1 `lab-flowchart.js:2291,2304,3214,3224`.
- **제안:** 입력/출력 포트 의미를 분명히 하고 기존 선 교체는 명시적인 동작으로 처리합니다. 현재 엔진은 처리 1출구·판단 2출구를 요구하므로 V1처럼 다중 출구를 무조건 허용하는 수정은 피해야 합니다.

## 실행·피드백의 추가 차이

1. **변수의 직전값 의미가 달라졌습니다.** V1은 그 변수를 다시 대입할 때만 직전값을 바꿉니다. 현재는 모든 실행 단계마다 전체 변수를 복사합니다. `x=1 → x=2` 뒤에는 현재2/직전1이지만 출력만 지나도2/2가 됩니다. 순수 실행과 현재 UI 갱신식으로 재현했습니다. 현재 `flow-execution.tsx:21,23`; V1 `lab-flowchart.js:3721`.
2. **라면이 완성돼도 출력란은 ‘대기 중…’입니다.** 정답 그래프 실행은 정상 종료되지만 `출력:` 로그가 없어서 결과 칸이 갱신되지 않습니다. V1의 라면 완성·순차 구조 해설·다음 단계 안내도 빠졌습니다. 현재 `flow-execution.tsx:24,39`; V1 `lab-flowchart.js:538,586,628`. 학습 성공 안내를 복원하되 제출 완료로 자동 처리해서는 안 됩니다.
3. **완료 뒤 실행 버튼이 비활성화됩니다.** 자동 실행 상태도 남아 완료 후 비활성 ‘일시정지’로 표시될 수 있습니다. V1은 다시 실행을 누르면 새 실행을 준비합니다. 현재 `flow-execution.tsx:26`; V1 `lab-flowchart.js:3708,4061`. 완료 때 ‘다시 실행’으로 바꾸는 편이 명확합니다.
4. **시작 기호 재추가가 불편해졌습니다.** 현재 단말은 항상 ‘종료’로 추가합니다. 시작 삭제 후 단말을 추가하면 시작 없는 종료 두 개가 됩니다. V1은 빠진 역할에 맞춰 시작/종료를 만들고 중복을 안내합니다. 현재 `flowchart-studio.tsx:61`; V1 `lab-flowchart.js:2661,2674`.
5. **AI 처방의 후보 범위가 줄었습니다.** V1은 현재/목표에서 목표 요약·핵심 변수·레시피를 만들고 선택 카드에서 조건을 추출합니다. 현재는 cards만 갱신하여 현재/목표만 입력한 학생의 조건은 빈 채로 남을 수 있습니다. 이후 기본 검사에는 조건이 필요합니다. 현재 `flowchart-studio.tsx:104`, `src/lib/classroom/review/project.ts:59`; V1 `lab-flowchart.js:2080,2158`. 운영 호출 없이 요청/응답 코드로 확인했으며 실제 모델 품질은 평가하지 않았습니다.

## V1을 그대로 따라도 별도로 고칠 학습 내용

- **‘비밀번호 5회 검증’** 예시에는 실제 5회 제한·반복 구조가 없습니다. 현재 `flowchart-presets.ts:40`과 V1 `lab-flowchart.js:1805`에 함께 있는 문제이므로 이식 누락으로 분류하지 않습니다. 제목과 실제 알고리즘을 맞추는 별도 내용 수정이 필요합니다.
- 예시의 카드 조건은 `현재 시각 <= 07:30`인데 현재 기호는 `7시 30분 이전인가요?`입니다. 포함 경계가 모호해졌으므로 `7시30분이거나 그 이전인가요?`처럼 표현을 일치시키는 편이 좋습니다. 현재 `flow-experience.ts:26`.
- PNG 저장 기능 자체는 있지만 V1의 구획된 포트폴리오·AI 확인 상태 표현은 단순 텍스트+그림으로 축소됐습니다. 문구 누락을 먼저 수정한 뒤 제출 작품의 읽기 순서를 개선할 수 있습니다.

## 유지할 합의와 제외한 후보

- CS Class 공통 헤더·단계·진도, useWork 단일 저장, 현재 검증/이전 제출 구분, 명시적 AI 요청·채택, 교사 미리보기 AI 제한, 외부 띵커보드 제외는 합의된 경계입니다. 이를 V1 누락으로 세지 않았습니다.
- V1에는 줌 함수가 있지만 공개 UI 호출/버튼은 확인되지 않아 ‘줌 복원 누락’으로 보고하지 않습니다.

- 예시 기획서 접기 때 제목 숨김 규칙은 현재 CSS에 있으므로 오류 후보에서 제외했습니다.
