# Design System: CS Class

갱신: 2026-10-14(Asia/Seoul). 공개 홈과 로그인·대시보드의 시각 디자인 기준, 수업 화면과 선택 복습의 UI 레이아웃 명세입니다. 제품 정책은 [PRD](PRD.md), 실행 및 검증 절차는 [DEVELOPMENT](DEVELOPMENT.md), 상태는 [HANDOFF](HANDOFF.md)를 따릅니다.

## 1. Visual Theme & Principles

중학생이 매일 사용하는 정보 수업 플랫폼입니다. 담백한 한국어, 넓은 여백, 읽기 쉬운 큰 제목, 실제 사용 과정을 투명하게 보여주는 화면으로 구성합니다. 학생의 눈높이에 맞춘 존중의 태도를 유지하며 직관적이고 친절한 정보 전달을 지향합니다.

- **여백과 밀도 (Density):** 한 화면 구간에서는 한 가지 핵심 내용에 집중합니다. 넉넉한 여백과 높은 가독성을 균형 있게 유지합니다.
- **손들기 일시 중지:** 학생 헤더의 손들기 버튼, 교사의 요청 패널·건수 안내와 전용 래퍼를 마운트하지 않습니다. 기존 Flex/Grid 흐름으로 남은 요소를 재배치하고 대체 플레이스홀더·안내 배너는 추가하지 않습니다. 저장·메뉴·수동 새로고침의 접근성을 유지합니다.
- **시각적 질서 (Hierarchy):** 제목과 카드 배치의 일관된 여백으로 정돈된 리듬을 만듭니다. 콘텐츠 간의 위계와 경계를 명확히 하여 학생의 인지 부하를 줄입니다.
- **인터랙션 원칙 (Motion):** 공개 홈의 대표 시연과 조작 피드백에 가벼운 트랜지션(160~240ms)을 집중하고, 학습 작업 공간에서는 정보 확인과 조작의 명확성을 최우선으로 합니다.
- **타이포그래피:** 프로젝트 로컬의 Pretendard Variable을 기본 글꼴로 사용합니다.

## 2. Design Tokens & Semantic Roles

### 2.2 타이포그래피 스케일 (Typography Rules)

- **기본 글꼴 체계:** `var(--font-pretendard)`, "Malgun Gothic", sans-serif.
- **헤드라인 크기 및 행간:**
  - 대형 첫 제목: 데스크톱 최대 82px (행간 1.2), 모바일 34~50px.
  - 구간 제목 (h2): 28~44px (굵기 600~700). 크기와 여백으로 명확한 계층 분리.
  - 소제목 (h3): 20~26px (굵기 600).
- **본문 텍스트:**
  - 기본 본문: 15~16px (행간 1.65). 최대 읽기 너비 약 65ch (한국어 30~42자).
  - 보조 텍스트: 13~14px. 보조 설명 및 부가 메타데이터에 적용하며, 충분한 명암비를 유지합니다.
- **숫자 서식:** 대시보드 통계나 진도율 수치는 `tabular-nums`를 적용해 숫자 자릿수 변경 시 레이아웃 흔들림을 방지합니다.
- **문구 톤앤매너:** 학생에게 친근하고 정중한 `~해요`, 권유는 `~하세요`, 버튼은 `교실 입장`, `수업 시작`, `이어하기`처럼 간결한 명사형/동사형을 사용합니다. 과도한 수식어보다는 명확하고 직관적인 정보 전달을 우선합니다.

### 2.3 레이아웃 및 반응형 기준선 (Breakpoints)

- **데스크톱:** 최대 1,440px 기준 그리드 (콘텐츠 최대 너비 1,200~1,440px).
- **태블릿 / 서랍형 전환선 (820px):**
  - 화면 폭 820px 이하에서 대시보드 좌측 사이드바가 모바일 서랍형 메뉴(Drawer)로 전환됩니다.
  - 수업 상단 헤더의 제목과 저장 상태 배지가 세로 2줄로 유연하게 재배치됩니다.
- **모바일:** 390px 기준 (최소 320px까지 가로 스크롤 없이 유연하게 축소).
- **스크롤바 안정화:** 문서 루트(`html`)에 `scrollbar-gutter: stable`을 적용해 모달 열림이나 동적 콘텐츠 로드 시 레이아웃 흔들림(CLS)을 방지합니다.

## 3. 공통 컴포넌트 명세 (Global Components)

- **상단 글로벌 헤더:** 좌측 브랜드 로고, 중앙 목차 앵커, 우측 움직임 조절 아이콘 및 `교실 입장` 버튼의 3개 구획으로 나뉩니다.
- **버튼 (CTA):**
  - 주 버튼: Clear Blue 배경, 흰색 텍스트, 최소 높이 44~48px, 둥근 모서리 10~12px. 클릭 시 1px 미세 이동으로 즉각적 물리 반응 제공.
  - 보조 버튼: 투명 또는 옅은 무채색 표면. 주 버튼의 시각적 위계를 방해하지 않음.
  - 터치 타깃: 모바일과 데스크톱 모두 인터랙티브 요소는 최소 44×44px를 권장합니다.
- **입력창 (Input / Select):**
  - 상단 라벨, 하단 오류 메시지, 포커스 시 2px 파란색 테두리(`focus-visible: 2px solid #7399e8`).
  - 선택 메뉴(Select)는 16px 둥근 모서리의 공통 팝오버를 사용하며, 항목별 10px 라운드 및 파란 하이라이트를 적용합니다.
- **알림 및 토스트 (Toast):**
  - 수업 설정 저장 성공 등 피드백은 우측 하단에 약 4초간 토스트로 노출되며 본문 레이아웃을 밀어내지 않습니다.
  - 호버 또는 포커스 시 닫힘 타이머를 일시 중지하며 닫기 버튼을 제공합니다.
- **스켈레톤 및 로딩 상태:**
  - 첫 데이터 조회 시 실제 UI 영역 형태의 스켈레톤을 렌더링하며, 재조회 시에는 기존 화면을 유지한 채 미세 인디케이터만 표시합니다.

## 4. 도메인 전용 UI 컴포넌트 명세

### 4.1 수업 전용 공통 틀 (`LessonShell`)
<a id="수업-전용-공통-틀"></a>
<a id="수업-전용-공통-틀--2026-10-06-구현"></a>

학생 수업 화면은 대시보드의 좌측 메뉴를 숨기고 학습에 몰입할 수 있는 전용 셸(`LessonShell`)을 사용합니다.

- **헤더 구성:** 가용 화면 폭 전체를 활용하며, 수업 나가기, 줄바꿈 가능한 수업 제목, 저장 상태 배지, 학생 메뉴를 배치합니다. (양 끝 여백: 데스크톱 16px, 820px 이하 12px).
- **콘텐츠 영역 폭 기준선:**
  - 개념 학습: 최대 **1,120px** (목록 + 본문).
  - 일반 퀴즈: 최대 **880px**.
  - 프로그래밍 퀴즈: 최대 **1,040px**.
  - 실습 작업실 (기본): 최대 **1,440px**.
  - 작업실 넓게 보기: 브라우저 가용 폭 전체 (좌우 여백 16px / 모바일 12px).
- **실습 집중 모드:**
  - 단계 탭 우측의 `실습 집중 모드` 토글을 누르면 상단 안내 및 미션 상세가 접히고 작업실 캔버스가 전체 폭으로 확장됩니다.
  - 샌드위치, 추상화, 순서도, 프로그래밍, 일반 Entry 모두 동일한 집중 모드 인터랙션을 공유합니다.
- **논리적 포커스 복구:** 모달 닫힘, 미션 제출 완료, 폭 전환 시 포커스는 논리적 주 조작 대상(버튼, 입력창, 섹션 제목)으로 안전하게 이동해야 합니다.

### 4.2 저장 상태 배지 (`SaveStateBadge`) 및 이탈 가드 모달

수업 상단 헤더의 저장 상태 시각 표현 규격입니다.

| 상태 | 시각적 배지 표현 | 아이콘 및 색상 |
| :--- | :--- | :--- |
| `saved` (기록 있음) | `저장 완료` | 구름 체크 아이콘 (`#376FC8`), Quiet Slate 텍스트 |
| `saved` (초기 진입) | `아직 학습 기록이 없어요` | 텍스트 단독, Quiet Slate |
| `dirty` (미저장) | `저장하지 않은 변경 있음` | 주황색 점 인디케이터 (`#D97706`) |
| `saving` (저장 중) | `저장 중…` | 미세 펄스 애니메이션 |
| `failed` (저장 실패) | `저장 확인 필요` | 적색 경고 텍스트 (`#A12C28`), 오류 확인 버튼 |
| `conflict` (버전 충돌) | `저장 기록 충돌` | 노란색 충돌 배지, 비교 및 선택 모달 유도 |

- **이탈 가드 모달 (`NavigationGuardDialog`):**
  - 미저장(`dirty`) 상태에서 외부 링크 클릭 또는 로그아웃 시 화면 중앙 모달로 노출됩니다.
  - `저장 후 나가기` (주 버튼, Clear Blue) / `저장하지 않고 나가기` (보조 버튼, 파괴적 회색) / `취소` (텍스트 버튼).
  - Escape 키 또는 모달 바깥 클릭 시 `취소`로 안전하게 닫히며 원래 조작 버튼으로 포커스를 복구합니다.

### 4.3 3구간 원형 진도 게이지 (`ActivityProgressRing`)

대시보드 메인에서 정규 수업의 전체 필수 활동 완료율을 시각화하는 위젯입니다.

- **기하 구조:** SVG `viewBox="0 0 180 180"`, 중심 `(90, 90)`, 반지름 `78px`, 선 두께 `14px`.
- **3구간 120도 호 분할:**
  - 1구간 (0° ~ 120°): 개념 학습 (`#376FC8`, 트랙 `#DCE6F5`)
  - 2구간 (120° ~ 240°): 퀴즈 풀이 (`#8860BA`, 트랙 `#E8DEF4`)
  - 3구간 (240° ~ 360°): 실습 미션 (`#268673`, 트랙 `#D9EBE5`)
- **중앙 수치:** 정규 수업 필수 활동 합산 완료율 정수 퍼센트 (`#28548E`, 34px bold, `tabular-nums`) 및 하단 `전체 진도` 라벨.
- **인터랙티브 툴팁:** 마우스 호버 또는 키보드 포커스 시 해당 단계의 세부 완료 개수와 완료율 툴팁(`n/m개 완료 · p%`)을 중앙에 팝업.

### 4.4 학생·교사 대시보드
<a id="학생교사-대시보드"></a>
<a id="대시보드-파일럿--노션을-참고한-내-할-일"></a>

- **사이드바 반응형:** 821px 이상에서는 좌측 고정 사이드바로 표시되며, 820px 이하에서는 햄버거 메뉴를 통한 서랍형으로 전환됩니다.
- **교사 대시보드 툴바 (`TeacherToolbar`):** 담당 반 선택 셀렉터, 최종 갱신 시각, 수동 새로고침 버튼 배치.
- **내 할 일 (체크리스트):** 체크박스와 텍스트 행이 1개 단위를 이룹니다. 완료 시 취소선과 옅은 텍스트로 전환됩니다. Enter 추가/편집, Esc 취소의 키보드 접근성 제공.
- **일정 및 미니 달력:** 오늘 날짜와 일정이 존재하는 날을 강조 표시하며, 다가오는 일정 최대 5개를 날짜순으로 카드에 정돈합니다. 지난 일정은 native `<details>`로 접어둡니다.

### 4.5 로그인 화면과 공통 시각 기준
<a id="확정된-공통-기준"></a>

- **중앙 집중형 카드 레이아웃:** 인증 작업에 온전히 집중할 수 있도록 화면 중앙에 정돈된 입력 카드를 배치합니다. 상단에는 `CS Class` 심볼을 둡니다.
- **역할별 시각적 구분:**
  - 학생 로그인: 책 아이콘과 파란색 강조를 사용합니다.
  - 교사·강사 로그인: 학사모 아이콘을 사용하며, `Google 계정으로 로그인`(Clear Blue)과 `교사 비밀번호 로그인`(Teacher Purple `#79639F`)을 동일한 크기·위계로 위아래 나란히 배치합니다.
  - 비밀번호 변경 화면: 열쇠 아이콘으로 명확히 구분합니다.

## 5. 수업별 실습 작업실 레이아웃

### 5.1 프로그래밍 기초 실습 화면 구성
<a id="프로그래밍-13차시--경험-검토용-표현"></a>

운영 경로 `/classroom/programming-13`의 시각 구성 명세입니다.

- **실습 화면 2열 레이아웃:**
  - 1,340px 이상: 좌측 미션 안내(260px) + 우측 EntryJS 작업실을 16px 간격으로 나란히 배치.
  - 821~1,339px: 상단 안내(목표·실험 2열) + 하단 작업실.
  - 820px 이하: 상단 안내(1열) + 하단 작업실.
- **EntryJS 작업실 크기:** 실제 편집기 및 무대는 최소 가로 1,000px, 세로 660px(저해상도 620px)를 확보하며, 페이지 가로 스크롤 대신 작업실 내부 패닝/스크롤을 허용합니다.
- **하단 미션 탐색:** 좌측 `이전 미션`, 우측 `다음 미션` 버튼을 대칭 배치합니다. 수동 제출 성공 시 다음 미션 버튼이 시각적으로 강조됩니다.

### 5.2 알고리즘 선택 복습
<a id="알고리즘-선택-복습"></a>

#### 1. 문제 추상화 (`review-abstraction`)
- **노선도 전환 지도:** 일반 지도(건물/도로 포함)와 지하철 노선도(단순화)를 1개 캔버스 안에서 전환하여 추상화 원리를 체험합니다. 좁은 창에서는 역 이름과 환승 정보가 겹치지 않도록 좌표를 재정렬합니다.
- **4단계 워크북:** 좌측 닥터 말풍선 대화 + 우측 워크북 입력창으로 구성됩니다. 맥락 요소 7개는 칩(Chip) 형태로 배치되어 클릭으로 덜어내기/되살리기를 직관적으로 토글합니다.

#### 2. 알고리즘 설계 / 샌드위치 (`review-sandwich`)
- **조리대와 대화창:** 901px 이상에서 조리대와 명령 대화창을 **약 2:1** 비율로 가로 배치합니다. 900px 이하에서는 세로 1열로 배치합니다.
- **SVG 높이 제한:** 큰 조리대 일러스트는 최대 450px(낮은 창 300~400px)로 제한하여 1280×720 해상도에서도 명령 입력창이 스크롤 없이 노출되도록 보장합니다.
- **명령 대화창:** 우측 파란색 말풍선(학생 명령), 좌측 밝은 회색 말풍선(로봇 응답)으로 시각적으로 구분하며, 하단에 누적 실행 기록 바를 둡니다.

#### 3. 순서도 연구소 (`review-flowchart`)
- **퍼즐 실습:** 보관함(좌) / 조립 캔버스(중앙) / 실행 모니터(우)의 3열 레이아웃을 사용합니다.
- **예시 공방:** 자연어 카드(좌) / 다이어그램(우)의 2열 레이아웃을 사용합니다.
- **자유 공방:** 기획서(300px) / 기호 보관함(100px) / 무한 캔버스 / 실행 과정 모니터(220px)의 4열 레이아웃을 지원하며, 기획서와 실행 과정은 필요 시 얇게 접을 수 있습니다.
- **모니터 구성:** 상단 흰색 변수표(현재값/직전값)와 하단 어두운 콘솔창으로 분리하여 실행 상태를 명확히 관찰할 수 있습니다.
- **기호 색상 규격:** 단말(시작/종료) 보라, 자료(입출력) 초록, 판단(조건) 주황, 처리(연산) 파랑으로 학습 의미를 전달합니다.

## 6. 접근성 및 UI 가이드라인 (Accessibility & Best Practices)

- **명암비 기준 (WCAG AA):** 본문 텍스트는 배경 대비 4.5:1 이상, 버튼 및 주요 경계선은 3:1 이상의 권장 명암비를 충족하여 조도가 다양한 교실 환경에서도 안정적인 가독성을 확보합니다.
- **움직임 감축 (`prefers-reduced-motion`):**
  - 공개 홈은 상단에 수동 모션 토글을 지원하며, OS 설정 또는 사용자 토글 해제 시 장식용 인터랙션을 정적인 화면으로 안전하게 대체합니다.
- **UI 품질 권장 원칙 (Design Considerations):**
  - **콘텐츠 중심의 단정한 인터페이스:** 학습 본질과 에디터 조작에 집중할 수 있도록, 정보 전달을 보조하는 기능적 시각 요소를 중심으로 단정하게 구성합니다.
  - **일관된 색상 및 표면 토큰 활용:** 텍스트와 주요 액션은 토큰 시스템(`Ink`, `Clear Blue`)을 우선 따르며, 새로운 강조색이나 효과는 수업 활동의 특성(단계별 시각화, 상태 배지 등)에 맞춰 목적이 분명할 때 유연하게 확장합니다. 그림자는 계층 구분을 위해 정의된 표면 토큰을 우선 활용합니다.
  - **유연하고 견고한 반응형 처리:** 작은 화면에서도 가독성이 유지되도록 최소 폰트 크기(권장 13px 이상)를 확보하고, 무리한 글자 축소보다는 줄바꿈, 2열→1열 재배치, 또는 작업실 내부 패닝/스크롤과 같은 유연한 대안을 우선 적용합니다.
  - **키보드 접근성과 포커스 표시 보존:** 키보드 탐색 사용자를 위해 `focus-visible` 아웃라인 등 시각적 포커스 인디케이터가 명확히 인지될 수 있도록 유지합니다.
