# Design System: CS Class

갱신: 2026-10-13(Asia/Seoul). 공개 홈과 로그인·대시보드의 시각 디자인 기준, 수업 화면과 선택 복습의 UI 레이아웃 명세입니다. 제품 정책은 [PRD](PRD.md), 실행 및 검증 절차는 [DEVELOPMENT](DEVELOPMENT.md), 상태는 [HANDOFF](HANDOFF.md)를 따릅니다.

## 1. Visual Theme & Atmosphere

중학생이 매일 사용하는 정보 수업 플랫폼입니다. 담백한 한국어, 넓은 여백, 읽기 쉬운 큰 제목, 실제 사용 과정을 투명하게 보여주는 화면으로 구성합니다. 학생을 어린아이처럼 대하지 않으며 감성적인 교육 홍보 문구를 반복하지 않습니다.

- **디자인 밀도 (Density 4/10):** 한 화면 구간에서는 한 가지 핵심 내용에 집중합니다. 넉넉한 여백과 충분한 가독성을 함께 유지합니다.
- **변주와 리듬 (Variance 5/10):** 제목과 제품 프레임의 크기·배치로 자연스러운 리듬을 만듭니다. 과도한 비대칭이나 복잡한 겹침은 피합니다.
- **모션 원칙 (Motion 6/10):** 공개 홈의 대표 시연에 인터랙션을 집중하고, 학생·교사 작업 공간에서는 정보 확인과 조작의 명확성을 최우선으로 합니다.
- **타이포그래피:** 프로젝트 로컬의 Pretendard Variable을 기본 글꼴로 사용합니다.

## 2. Color Palette & Roles

밝은 무채색 표면 위에 맑은 파랑(`Clear Blue`)을 주요 강조색으로 사용하고, 절제된 보조색을 작은 그래픽과 옅은 표면에 배합합니다.

| Canvas White | `#FFFFFF` | 기본 페이지 배경 및 주요 제품 카드 표면 |

| Fine Border | `#E3E8EF` | 입력창, 카드, 프레임 경계선 |
| Clear Blue | `#376FC8` | 주 액션 버튼, 활성 탭, 키보드 포커스 링 |

- **접근성 대비:** 본문 텍스트는 배경 대비 4.5:1 이상, 큰 텍스트 및 핵심 UI 경계선은 3:1 이상의 명암비를 보장합니다.

## 3. Typography Rules

- **기본 글꼴 체계:** `Pretendard Variable`, `Noto Sans KR`, `Malgun Gothic`, sans-serif.
- **헤드라인 크기 및 행간:**
  - 대형 첫 제목: 데스크톱 최대 82px (행간 1.2), 모바일 34~50px. 단색 파랑으로 핵심 어절 강조.
  - 구간 제목 (h2): 28~44px (굵기 600~700). 크기와 여백으로 명확한 계층 분리.
  - 소제목 (h3): 20~26px (굵기 600).
- **본문 텍스트:**
  - 기본 본문: 16~18px (행간 1.6~1.75). 최대 읽기 너비 약 65ch (한국어 30~42자).
  - 보조 텍스트: 14px 이상. 핵심 안내를 과도하게 작은 회색 글자로 숨기지 않음.
- **숫자 및 서식:** 테이블이나 통계에서는 `tabular-nums` 또는 등폭 글꼴을 활용해 숫자 정렬을 맞춥니다.
- **문구 톤앤매너:** 학생에게 친근하고 정중한 `~해요`, 권유는 `~하세요`, 버튼은 `교실 입장`, `수업 시작`, `이어하기`처럼 간결한 명사형/동사형을 사용합니다. 과장된 교육 슬로건은 배제합니다.

## 4. Component Stylings

- **상단 글로벌 헤더:** 좌측 브랜드 로고, 중앙 목차 앵커, 우측 움직임 조절 아이콘 및 `교실 입장` 버튼의 3개 구획으로 나뉩니다.
- **버튼 (CTA):**
  - 주 버튼: Clear Blue 배경, 흰색 텍스트, 최소 높이 44~48px, 둥근 모서리 12~14px. 클릭 시 1px 미세 이동으로 즉각적 반응 제공.
  - 보조 버튼: 투명 또는 옅은 무채색 표면. 주 버튼의 시각적 위계를 방해하지 않음.
  - 터치 타깃: 모바일과 데스크톱 모두 인터랙티브 요소는 최소 44×44px를 보장합니다.
- **입력창 (Input / Select):**
  - 상단 라벨, 하단 오류 메시지, 포커스 시 2px 파란색 테두리(`focus-visible`).
  - 선택 메뉴(Select)는 16px 둥근 모서리의 공통 팝오버를 사용하며, 항목별 10px 라운드 및 파란 하이라이트를 적용합니다.
- **알림 및 토스트 (Toast):**
  - 수업 설정 저장 성공 등 피드백은 우측 하단에 약 4초간 토스트로 노출되며 본문 레이아웃을 밀어내지 않습니다.
  - 호버 또는 포커스 시 닫힘 타이머를 일시 중지하며 닫기 버튼을 제공합니다.
- **스켈레톤 및 로딩 상태:**
  - 첫 데이터 조회 시 실제 UI 영역 형태의 스켈레톤을 렌더링하며, 재조회 시에는 기존 화면을 유지한 채 미세 인디케이터만 표시합니다.

## 5. Layout Principles

- **반응형 기준선:**
  - 데스크톱: 1440px 기준 그리드 (콘텐츠 최대 너비 약 1200~1440px).
  - 태블릿 / 좁은 창: 820px 경계선에서 사이드바를 모바일 서랍형 메뉴로 전환.
  - 모바일: 390px 기준 (최소 320px까지 가로 스크롤 없이 유연하게 축소).
- **스크롤바 안정화:** 문서 루트(`html`)에 `scrollbar-gutter: stable`을 적용해 모달 열림이나 동적 콘텐츠 로드 시 레이아웃 흔들림(CLS)을 방지합니다.
- **그리드 및 여백:**
  - 기본 좌우 여백: 데스크톱 20~64px, 모바일 12~16px.
  - 구간 사이 여백: `clamp(4rem, 9vw, 8rem)`.

## 6. Motion & Interaction

- **공개 홈 전환 인터랙션:** 스크롤 위치에 따라 한 프레임 안에서 개념학습 → 퀴즈 → 실습 단계가 자연스럽게 전환됩니다.
- **전환 속도:** 인터랙티브 피드백 160~240ms, 콘텐츠 패널 전환 300~500ms. 과도한 바운스 모션은 지양합니다.
- **접근성 (`prefers-reduced-motion`):**
  - 공개 홈은 기본적으로 움직임이 활성화되어 있으나, 상단에 수동 모션 토글을 제공합니다.
  - OS의 움직임 줄이기 설정이 켜져 있거나 토글이 해제되면 모든 고정 패럴랙스 및 장식 애니메이션이 비활성화됩니다.

## 7. Anti-Patterns (금지 사항)

- 과장된 교육 마케팅 문구, 영문 대문자 표제 과용, 만화풍 캐릭터 남발.
- 특정 차시(순서도 등)를 플랫폼 전체의 정체성으로 오인하게 만드는 홈 구성.
- 네온/형광 계열 색상, 대형 그라데이션 타이틀, 무분별한 그림자 효과.
- 화면 크기에 억지로 맞추기 위해 텍스트 폰트 크기를 비정상적으로 줄이거나 내용을 임의 생략하는 행위.
- 확인되지 않은 가짜 통계나 점수 조작 요소 표시.

## 8. 화면별 상세 디자인

### 로그인 화면과 공통 시각 기준
<a id="확정된-공통-기준"></a>

- **중앙 집중형 카드 레이아웃:** 불필요한 좌측 대형 홍보 영역을 배제하고 화면 중앙에 정돈된 입력 카드를 배치합니다. 상단에는 `CS Class` 브랜드 심볼을 둡니다.
- **역할별 시각적 구분:**
  - 학생 로그인: 책 아이콘과 파란색 강조를 사용합니다.
  - 교사·강사 로그인: 학사모 아이콘을 사용하며, `Google 계정으로 로그인`(Clear Blue)과 `교사 비밀번호 로그인`(Teacher Purple `#79639F`)을 동일한 크기·위계로 위아래 나란히 배치합니다.
  - 비밀번호 변경 화면: 열쇠 아이콘으로 명확히 구분합니다.
- **인증 상태 피드백:**
  - 초기 서버 세션 확인 중에는 홈의 입장 버튼에 `입장 준비 중`과 회전 표시를 노출하며, 입력창 및 이동 조작은 잠그지 않습니다.
  - 오류 메시지는 해당 입력창 바로 아래에 붉은색과 함께 명확한 텍스트로 안내합니다.

### 수업 전용 공통 틀 (`LessonShell`)
<a id="수업-전용-공통-틀--2026-10-06-구현"></a>
<a id="수업-전용-공통-틀"></a>

학생 수업 화면은 대시보드의 좌측 메뉴를 숨기고 학습에 몰입할 수 있는 전용 셸(`LessonShell`)을 사용합니다.

- **헤더 구성:** 가용 화면 폭 전체를 활용하며, 수업 나가기, 줄바꿈 가능한 수업 제목, 저장 상태 배지, 학생 메뉴를 배치합니다. (양 끝 여백: 데스크톱 16px, 820px 이하 12px).
- **콘텐츠 영역 폭 기준선:**
  - 개념 학습: 최대 **1,120px** (목록 + 본문).
  - 일반 퀴즈: 최대 **880px**.
  - 프로그래밍 퀴즈: 최대 **1,040px**.
  - 실습 작업실 (기본): 최대 **1,440px**.
  - 작업실 넓게 보기: 브라우저 가용 폭 전체 (좌우 여백 16px / 모바일 12px).
- **실습 집중 모드:**
  - 단계 탭 우측의 `실습 집중 모드` 토글을 누르면 상단 안내 및 미션 상세가 접히고 작업실 캔버스가 전체 폭으로 확장됩니다.
  - 샌드위치, 추상화, 순서도, 프로그래밍, 일반 Entry 모두 동일한 집중 모드 인터랙션을 공유합니다.
- **논리적 포커스 복구:** 모달 닫힘, 미션 제출 완료, 폭 전환 시 포커스는 논리적 주 조작 대상(버튼, 입력창, 섹션 제목)으로 안전하게 이동해야 합니다. (React Effect 구현 검증은 [DEVELOPMENT](DEVELOPMENT.md#검증-노하우-기능별) 참조).

#### 학생 수업 저장 표현

저장 표현은 다음 기준을 따릅니다. 로컬 검증·운영 반영 상태는 [HANDOFF](HANDOFF.md#현재-작업-상태)에서 구분합니다.

- 학생 지속 헤더에 `저장` 버튼과 `저장 완료 / 저장하지 않은 변경 있음 / 저장 중… / 저장 확인 필요 / 저장 기록 충돌`을 둡니다. 모바일·낮은 창·집중 모드에도 접근 가능하며 저장 상태 변경으로 헤더/편집기를 교체하지 않습니다.
- 실제 내용이 바뀐 경우에만 미저장으로 표시합니다. 위치만 바뀐 경우에는 경고하지 않고 다음 내용 저장 때 위치를 기록합니다. 저장 중 추가 편집은 요청 성공 후에도 미저장으로 표시합니다.
- 외부 이동 대화상자는 `저장 후 나가기 / 저장하지 않고 나가기 / 취소`를 명시합니다. Escape·닫기·바깥 클릭은 취소로 처리하고 시작 조작으로 초점을 복구합니다. 처리 중 중복 선택과 부모 대화상자/메뉴의 Escape 전파를 구분합니다.
- 성공 status는 초점을 빼앗지 않습니다. 실패·충돌은 현재 입력 보존과 재시도/비교 조작을 안내합니다. 교사 체험에는 학생 서버 저장 버튼을 노출하지 않습니다.
- 손들기는 나가기 선택을 띄우지 않습니다. 현재 작품을 저장해 전달하는 처리/실패 상태를 도움 요청 영역에 표시합니다. 기획서 적용 전 제안 dialog를 저장으로 자동 적용하지 않습니다.
- UI·iframe 단축키·native 미저장 경고의 계약은 [개발 안내](DEVELOPMENT.md#학생-수업-수동-저장-아키텍처-및-계약)를 따릅니다.

### 학생·교사 대시보드
<a id="학생교사-대시보드"></a>

`AppShell` 기반의 사이드바 탐색 구조를 공유하며 역할에 따라 최적화된 대시보드를 제공합니다.

- **사이드바 반응형:** 821px 이상에서는 좌측 고정 사이드바로 표시되며, 820px 이하에서는 햄버거 메뉴를 통한 서랍형으로 전환됩니다.
- **학생 대시보드 메인 게이지:**
  - 동일한 120도 호(Arc) 3개로 구성된 원형 게이지를 제공합니다: 개념(파랑 `#376FC8`), 퀴즈(보라 `#79639F`), 실습(청록 `#20B2AA`).
  - 가운데는 정규 수업 기준 전체 필수 활동 합산 완료율을 숫자로 표시합니다.
  - 마우스 호버 및 키보드 탐색 시 각 구간의 세부 완료 개수와 완료율 툴팁을 표시합니다.
- **교사 대시보드 및 툴바:**
  - 상단 `TeacherToolbar`에 담당 반 선택 셀렉터, 최종 갱신 시각, 수동 새로고침 버튼을 배치합니다.
  - `교사가 확인할 일` 막대는 단계별 필수 활동을 모두 마친 학생 수 비율을 시각화합니다.
  - 담당 반 준비표: 각 반별 열린 수업 현황과 설정 바로가기를 깔끔한 표 형태로 제공합니다.

### 대시보드 화면 상세 (할 일과 일정)
<a id="대시보드-파일럿--노션을-참고한-내-할-일"></a>

- **내 할 일 (개인 체크리스트):**
  - 체크박스와 텍스트 행이 1개 단위를 이룹니다. 완료 시 취소선과 옅은 텍스트로 전환됩니다.
  - 마우스 클릭 없이도 Enter로 항목 추가 및 편집 완료, Esc로 취소, IME 조합을 배려한 키보드 인터랙션을 제공합니다.
- **일정 및 미니 달력:**
  - 이번 달 달력에서 오늘 날짜와 일정이 존재하는 날을 강조 표시합니다.
  - 다가오는 일정 최대 5개를 날짜순으로 카드에 정돈하고, 지난 일정은 native `<details>`로 접어둡니다.
  - 금옥중학교 정보 시간표는 교시, 시작 시각, 출처 배지와 함께 표시됩니다.

### 프로그래밍 13차시 화면 구성
<a id="프로그래밍-13차시--경험-검토용-표현"></a>

운영 경로 `/classroom/programming-13`의 시각 구성 명세입니다.

- **실습 화면 2열 레이아웃:**
  - 1,340px 이상: 좌측 미션 안내(260px) + 우측 EntryJS 작업실을 16px 간격으로 나란히 배치.
  - 821~1,339px: 상단 안내(목표·실험 2열) + 하단 작업실.
  - 820px 이하: 상단 안내(1열) + 하단 작업실.
- **EntryJS 작업실 크기:** 실제 편집기 및 무대는 최소 가로 1,000px, 세로 660px(저해상도 620px)를 확보하며, 페이지 가로 스크롤 대신 작업실 내부 패닝/스크롤을 허용합니다.
- **하단 미션 탐색:** 좌측 `이전 미션`, 우측 `다음 미션` 버튼을 대칭 배치합니다. 수동 제출 성공 시 다음 미션 버튼이 시각적으로 강조됩니다.

### 알고리즘 선택 복습
<a id="알고리즘-선택-복습"></a>

#### 1. 문제 추상화 (`review-abstraction`)
- **노선도 전환 지도:** 일반 지도(건물/도로 포함)와 지하철 노선도(단순화)를 1개 캔버스 안에서 전환하여 추상화 원리를 체험합니다. 좁은 창에서는 역 이름과 환승 정보가 겹치지 않도록 좌표를 재정렬합니다.
- **4단계 워크북:** 좌측 닥터 말풍선 대화 + 우측 워크북 입력창으로 구성됩니다. 맥락 요소 7개는 칩(Chip) 형태로 배치되어 클릭으로 덜어내기/되살리기를 직관적으로 토글합니다.

#### 2. 알고리즘 설계 / 샌드위치 (`review-sandwich`)
- **조리대와 대화창:** 901px 이상에서 조리대와 명령 대화창을 **약 2:1** 비율로 가로 배치합니다. 900px 이하에서는 세로 1열로 배치합니다.
- **SVG 높이 제한:** 큰 조리대 일러스트는 최대 450px(낮은 창 300~400px)로 제한하여 1280×720 해상도에서도 명령 입력창이 스크롤 없이 노출되도록 보장합니다.
- **명령 대화창:** 우측 파란색 말풍선(학생 명령), 좌측 밝은 회색 말풍선(로봇 응답)으로 시각적으로 구분하며, 하단에 누적 실행 기록 바를 둡니다.

#### 3. 순서도 연구소 (`review-flowchart`)
- **퍼즐 실습:** 보관함(좌) / 조립 캔버스(중앙) / 실행 모니터(우)의 3열 레이아웃을 사용합니다.
- **예시 공방:** 자연어 카드(좌) / 다이어그램(우)의 2열 레이아웃을 사용합니다.
- **자유 공방:** 기획서(300px) / 기호 보관함(100px) / 무한 캔버스 / 실행 과정 모니터(220px)의 4열 레이아웃을 지원하며, 기획서와 실행 과정은 필요 시 얇게 접을 수 있습니다.
- **모니터 구성:** 상단 흰색 변수표(현재값/직전값)와 하단 어두운 콘솔창으로 분리하여 실행 상태를 명확히 관찰할 수 있습니다.
- **기호 색상 규격:** 단말(시작/종료) 보라, 자료(입출력) 초록, 판단(조건) 주황, 처리(연산) 파랑으로 학습 의미를 전달합니다.
