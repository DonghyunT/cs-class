# CS Class 작업환경과 도구

갱신: 2026-09-26 · 추천 구성, 실제 연결, 아직 하지 않은 일을 구분합니다.

## 기술 선택의 현재 위치

선생님은 설치 전에 대화로 작업환경을 구체화하기를 원합니다. 준비 단계에서 문서와 V1 보관 구조를 정리했으며 앱 설치·스택 전환은 수행하지 않습니다.

| 구성 | 추천 이유 | 현재 상태 |
|---|---|---|
| Next.js + React | 공개·학생·교사 화면과 서버 기능을 구성하는 기반 | 추천 후보, 미설치 |
| TypeScript | 학생·반·작업 상태 등 코드 연결 오류를 개발 중 점검 | 추천 후보, 미설치 |
| Tailwind CSS | 간격·색·창 크기 대응을 일관되게 구성 | 추천 후보, 미설치 |
| shadcn/ui | 버튼·메뉴·팝업의 소스를 가져와 우리 디자인으로 수정 | 추천 후보, 미설치 |
| Context7 | 사용 버전에 맞는 라이브러리 문서·예제 조회 | 적극 활용 방향에 동의, 연결 전 |
| Figma | 디자인 비교·대표 화면 검토 | 계정 확인 도구 연결 성공. 파일별 읽기·생성·편집 미검증 |
| 브라우저 도구 | 실제 화면·조작·창 크기·키보드 검증 | 이 대화에서 참고 사이트 열람에 사용 |

shadcn/ui는 Tailwind 기반 화면 부품의 코드를 직접 조정하는 방식입니다. 기본 흑백 예제가 제품의 스타일을 강제하지 않습니다. Next.js 도입이 인증·권한·저장 설계를 대신하지는 않습니다. 라이브러리 선택과 디자인 선택을 구분합니다.

새 라이브러리 사용이나 버전에 민감한 작업에서는 Context7 또는 공식 문서를 확인합니다. 공식·관리되는 스킬을 우선 검토하고 필요한 역할에만 적용합니다. 호출 수나 설치한 도구 수를 성과로 삼지 않습니다.

## 현재 로컬 실행

현재 실행 대상은 빌드 도구 없는 web/ 시안입니다. 새로 쓸 앱의 폴더 구조와 패키지 관리자는 아직 결정하지 않았습니다. 과거 V1 앱·서버·도구는 archive/v1/에 보관했습니다. 현재 CI는 web/의 두 JavaScript 파일 문법만 검사하며 기능 검증을 대체하지 않습니다. 현재 PC에서 Node.js 24.19.0, npm 11.17.0을 확인했습니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

브라우저 주소는 http://127.0.0.1:8765/ 입니다. Python이 현재 PC에 준비되어 있는지 실행 시 확인합니다. 이 정적 시안은 서버 API·실제 인증을 시험하지 않습니다. 새 도구를 설치할 때 런타임·패키지 관리자 버전을 확인하고 재현에 필요한 잠금 파일·실행 명령을 기록합니다.

## 외부 환경과 분리

- Git 원격: 비공개 DonghyunT/cs-class. 준비 작업을 main에 통합하며 이후 main을 새 작업의 기준으로 사용합니다.
- 현재 시안 배포 프로젝트: Vercel cs-class, Root Directory web. [2026-09-25 배포 근거](CS_CLASS_DEPLOYMENT.md)를 참고하며 현재 실시간 상태와 구분합니다.
- 실제 운영용 Firebase 후보는 cs-class-f74c4이며 미연결입니다. 별도 개발용 Firebase는 아직 생성하지 않았다는 인수인계 기록이 있습니다. 이번에는 클라우드 상태를 재조회하지 않았습니다.
- V1의 donghyun-algo와 V2 개발 프로젝트는 CS Class의 시험 데이터 대상이 아닙니다. 새 연결·배포 전에 실제 대상 프로젝트와 환경변수를 확인합니다.
- archive/v1/api/와 archive/v1/js/data/firebase-config.js는 V1 자산입니다. 루트의 V1 Firebase 연결 설정도 보관함으로 이동했습니다. 새 앱이 이를 자동으로 사용하지 않도록 새 환경 구성 때 경계를 확인합니다. 운영 자료를 변경하지 않는 작은 검증부터 시작합니다.

## 다른 PC에서 이어가기

먼저 Git 변경과 미전송 커밋을 보존하고 원격을 확인합니다. HANDOFF에 적힌 작업 브랜치를 기준으로 이어가며 main을 무조건 최신 제품으로 생각하지 않습니다. 패키지 설치·서비스 로그인·비밀 환경변수는 Git만으로 전달되지 않습니다. 현재 PC에서 존재와 접근을 확인하고, 비밀값 대신 준비 절차를 기록합니다.
