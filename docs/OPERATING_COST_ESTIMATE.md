# 운영비 예상안

검토일: 2026-09-28. 사용자 요청에 따라 공식 요금표와 가정한 사용량으로 계산한 **예산 검토 자료**입니다. 실제 계정 청구서·서비스 사용량을 확인한 견적이 아니며, 요금제·공급자·AI 모델 선택이나 결제·서비스 연결 승인이 아닙니다. 현재 [1차 완료 목표](PRD.md#1차-구현-완료-목표--실제-계정과-저장-연결)는 로그인·수업 지정·검증용 활동·저장·재접속 후 복원이며 AI 도입 순서는 미정입니다.

**후속 결정:** 사용자는 월 4만 원을 참고 예산으로 수용했고, 무료로 사용할 AI API가 별도로 있다고 설명했습니다. AI 연결은 이후로 미루며 현재는 구현 지시문을 협의합니다. 아래 유료 AI 계산은 비교 자료로 보존하며 공급자 선택이나 월 10만 원 예산 채택을 뜻하지 않습니다.

## 계산 전제

- 한 반은 학생 27명, 전체는 11개 반 297명으로 계산합니다. 학생당 월 8차시를 가정합니다.
- 환율은 예산 계산용 **1달러 = 1,500원**입니다. 실제 환율을 조회한 값이 아닙니다.
- Vercel Pro 배포 관리자 1명과 Firebase 인증·Firestore Standard를 사용하는 구성을 비교용으로 가정합니다. 학생·교사의 앱 로그인 인원은 Vercel 배포 관리자 좌석 수가 아닙니다.
- 작업은 주로 텍스트·블록 데이터이며, DB 총 저장량 1GiB 이하·월 외부 전송량 10GiB 이하를 가정합니다. 장기 보관·인덱스 증가에 따라 달라질 수 있습니다.
- 학생당 수업 1회에 문서 읽기 300회·쓰기 100회를 가정합니다. 측정값이나 확정된 자동 저장 간격이 아닙니다. 교사 조회·보안 규칙·실시간 구독에 따른 추가 읽기도 실제 구현에서 측정해야 합니다.
- 가벼운 인증·저장 서버 처리가 Vercel 기본 제공량과 포함 크레딧 안에 들어간다는 가정입니다. EntryJS 실행 채점을 위한 별도 서버 환경은 이 계산에 포함하지 않습니다.
- 세금·카드 수수료·유료 도메인·대용량 파일·유료 백업·개발용 Codex/ChatGPT 구독은 별도입니다. 기존 팀의 다른 프로젝트 사용량도 합산하지 않았습니다.

## 기본 플랫폼

[Vercel Pro](https://vercel.com/docs/plans/pro-plan)는 월 20달러이며 배포 좌석 1개와 인프라 사용 크레딧 20달러가 포함됩니다. 플랫폼 요금과 포함 크레딧을 합쳐 40달러로 계산하지 않습니다. 여기서는 월 **30,000원**을 기본값으로 사용합니다. 포함 범위를 넘는 사용량과 추가 배포 좌석은 별도 과금입니다.

[Vercel Hobby](https://vercel.com/docs/plans/hobby)는 무료지만 개인의 비상업적 사용 조건이 있습니다. 학교 운영에 적용 가능하다고 단정하지 않고 Pro를 예산 기준으로 잡았습니다. Hobby 조건에 맞는 개인 시험이라면 기본료 30,000원이 빠질 수 있습니다. 학생 수만으로 Pro가 필수라고 판단한 것은 아닙니다.

[Firebase 요금표](https://firebase.google.com/pricing)상 이 규모의 SMS 없는 일반 인증은 무료 범위를 활용할 수 있습니다. [Firestore Standard](https://firebase.google.com/docs/firestore/pricing)는 프로젝트의 대상 DB 하나에 저장 1GiB, 일일 읽기 50,000회·쓰기 20,000회, 월 외부 전송 10GiB 등의 무료량을 제공합니다. Blaze는 고정 월 구독료가 있는 요금제가 아니라 사용량 과금이며 적용 가능한 무료량도 유지됩니다.

| 규모 | 월 학생 수업 참여 횟수 | 월 읽기 가정 | 월 쓰기 가정 |
| --- | ---: | ---: | ---: |
| 1개 반 | 216 | 64,800 | 21,600 |
| 11개 반 | 2,376 | 712,800 | 237,600 |

**무료 읽기·쓰기는 일별 기준이므로 위 월간 합계만으로 무료 여부를 판정할 수 없습니다.** 같은 날 수업이 몰리는 정도, 데이터 지역·크기, 조회 방식에 따라 비용이 달라집니다. 인증·DB·전송의 추가 비용에 대해 한 반은 월 0~1,000원, 전체는 0~5,000원을 임시 여유분으로 잡았습니다. 이는 공식 정액 요금이나 지역별 정확한 청구액이 아니라 소규모 시험 후 조정할 계획용 금액입니다.

## 향후 AI 검증

가격 비교용 모델로 [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)의 표준 텍스트 요금인 입력 100만 토큰당 0.75달러·출력 100만 토큰당 4.50달러를 사용합니다. 모델 선정이나 채점 품질 검증을 마쳤다는 뜻은 아닙니다.

검증 1회에 지시문·작품 데이터를 합쳐 입력 4,000토큰, 추론을 포함한 전체 과금 출력 1,000토큰을 가정하면 **0.0075달러 = 약 11.25원**입니다. 캐시·배치 할인은 적용하지 않았으며, 이미지·외부 도구·지역 처리 할증은 포함하지 않았습니다. 작품이 길어지거나 출력량이 늘어나면 비용도 증가합니다.

- **일반 사용:** 월 8차시 중 4차시에서 학생당 재시도 포함 2회 검증, 학생당 월 8회.
- **많이 사용:** 월 8차시 모두에서 학생당 재시도 포함 2회 검증, 학생당 월 16회.
- 자유 채팅을 무제한 제공하는 상황은 가정하지 않았습니다. 정해진 조건으로 판정 가능한 활동은 AI를 호출하지 않아도 되지만, 실행 채점 환경 자체의 서버 비용은 따로 검토해야 합니다.

| 규모 | 일반 사용 횟수 / 월 AI 비용 | 많이 사용 횟수 / 월 AI 비용 |
| --- | ---: | ---: |
| 1개 반 | 216회 / 2,430원 | 432회 / 4,860원 |
| 11개 반 | 2,376회 / 26,730원 | 4,752회 / 53,460원 |

## 월 합계와 제안 예산

아래 합계는 Pro 기본료·AI 계산액·임시 DB 등 여유분을 더한 값입니다. 위 전제가 유지될 때의 비교이며 세금 등 별도 항목은 포함하지 않습니다.

| 구성 | 1개 반 27명 | 11개 반 297명 |
| --- | ---: | ---: |
| 로그인·학습 저장, AI 없음 | 30,000~31,000원 | 30,000~35,000원 |
| AI 검증 일반 사용 | 32,430~33,430원 | 56,730~61,730원 |
| AI 검증 많이 사용 | 34,860~35,860원 | 83,460~88,460원 |

**예산 상태:** 1차 기본 플랫폼 월 4만 원은 참고 예산으로 수용했습니다. 전체 유료 AI 검증 확대 시 월 10만 원은 이전 제안이며 채택하지 않았습니다. 실제 결제·서비스 설정은 하지 않았습니다. 먼저 한 반에서 수업당 읽기·쓰기·전송량·서버 처리량을 측정하고, AI는 사용자의 별도 API 조건과 실제 사용량을 확인할 때 다시 검토합니다.

예산 금액이 자동 과금 한도를 뜻하지 않습니다. [Vercel 지출 관리](https://vercel.com/docs/spend-management)와 [Firebase 비용 관리](https://firebase.google.com/docs/projects/billing/avoid-surprise-bills)의 알림·차단 범위는 서로 다릅니다. Firestore는 예산 알림만으로 사용이 중단되지 않습니다. AI 도입 시에는 앱에서 학생별·수업별 호출 제한을 두는 방안과 사용량 알림을 별도로 설계해야 합니다.
