## Stitch 키 입력

PowerShell에 아래 블록 전체를 붙여넣고 실행한 뒤, 입력 안내가 나타나면 새 키를 붙여넣습니다. 실행 정책을 변경하지 않고 대화형 명령으로 처리합니다. 키 입력은 마스킹되며 값은 현재 Windows 사용자 환경변수에 등록됩니다. 키 자체를 명령문·채팅·문서에 적지 않습니다.

```powershell
& {
    $stitchSecret = Read-Host '새 Stitch API 키' -AsSecureString
    try {
        if ($stitchSecret.Length -lt 20) { throw '키가 너무 짧습니다. 저장하지 않았습니다.' }
        [Environment]::SetEnvironmentVariable('STITCH_API_KEY', [Net.NetworkCredential]::new('', $stitchSecret).Password.Trim(), 'User')
        '등록 완료. Codex를 완전히 종료한 뒤 다시 열어 주세요.'
    }
    finally { $stitchSecret.Dispose() }
}
```

Codex를 재실행한 뒤 이 채팅에서 이어갑니다. 등록 여부 확인 시 실제 키를 출력하지 않고 존재 여부만 확인합니다. Microsoft 문서: [실행 정책](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies), [Read-Host](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/read-host).
