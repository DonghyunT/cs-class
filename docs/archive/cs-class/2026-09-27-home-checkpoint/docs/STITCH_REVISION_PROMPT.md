# CS Class — 생성 시안 수정 요청

대상: [CS Class 랜딩페이지 디자인](https://stitch.withgoogle.com/projects/9952170337891001891)의 `CS Class 공개 홈 - 데스크톱`, `CS Class 공개 홈 - 모바일`.

선생님이 전체 디자인 방향에 동의하고 기능·문구 불일치 수정을 요청했습니다. 아래 요청문을 2026-09-27 Stitch MCP의 `edit_screens`로 두 기존 화면에 적용했습니다. 반환된 HTML을 검토한 뒤, 모바일에 누락된 Pretendard 적용과 `prefers-reduced-motion` 처리를 한 번 더 수정했습니다. 브랜드 로고는 수정 대상에 포함하지 않았습니다. 최종 화면 ID와 확인 결과는 [검토 기록](STITCH_REVIEW.md)에 있습니다.

```text
현재 ‘CS Class 공개 홈 - 데스크톱’과 ‘CS Class 공개 홈 - 모바일’의 전체적인 디자인, 배치, 색감과 여백은 유지해 주세요. 아래 내용은 실제 제품 요구사항에 맞추는 수정입니다. 데스크톱과 모바일에 동일하게 적용해 주세요.

1. 로그인 방식 바로잡기
- ‘반 코드’, ‘학교 코드’, ‘로그인 없이 입장’, ‘코드만으로 참여’ 등 코드 기반 입장 안내를 모두 제거해 주세요.
- 학생은 선생님이 미리 발급한 학번과 비밀번호로 로그인하며 반은 미리 배정됩니다. 학생 직접 회원가입은 없습니다.
- 입장 보조 문구는 ‘선생님께 안내받은 학번과 비밀번호로 입장해요.’로 통일해 주세요.
- 주요 버튼 ‘교실 입장’은 유지하고, 새 로그인 화면은 이번 수정에서 만들지 마세요.

2. 실제로 제공하지 않는 상태 제거하기
- ‘진행률 80%’, ‘4/5 완료’, ‘어제 3교시 저장됨’, ‘최근 저장’, ‘이전 저장 시점부터 재개’, ‘출석 인정’, ‘제출 완료’, ‘피드백 대기중’처럼 가상의 학습 통계·저장·출석·과제 상태를 제거해 주세요.
- ‘실시간 수업 현황’, ‘실제 수업에서도 즉시 실행 가능’처럼 동작이 확인되지 않은 실서비스 안내도 제거해 주세요.
- 이번 수업, 최근에 열어 본 수업, ‘수업 시작’, ‘이어하기’는 남겨 주세요. 제품 화면에는 ‘화면 예시’를 읽을 수 있는 크기로 표시해 주세요.
- ‘45분’, 정해진 학기·단원·차시 수 등의 가상 운영 정보와 가상의 교사 이름은 생략해 주세요.
- 수업 시작을 설명하는 데 공지·알림을 추가하지 마세요. 교사 미리보기는 반 선택, 열린 수업, 이번 수업 지정에 한정해 주세요.

3. 수업 구성 예시 유지하기
- ‘개념학습 → 퀴즈 → 실습’이 하나의 수업 프레임 안에서 전환되는 구성과 세 단계 선택기는 유지해 주세요.
- 개념 설명·퀴즈·실습 내용은 ‘수업 구성 예시’임을 표시해 주세요. 특정 단원을 홈페이지 전체의 대표 메시지로 확대하지 마세요.
- 모든 수업이 고정된 세 단계라는 표현이나, 정답을 맞혀야 다음 화면에 진입한다는 제한을 넣지 마세요.
- 단계 선택기를 클릭·키보드로 조작할 수 있도록 설계해 주세요. 모바일에서는 긴 스크롤 고정 없이 읽을 수 있는 크기를 유지해 주세요.
- 실제 동작을 생성하지 못했다면 완료했다고 표시하지 말고 세 상태와 전환 사양을 함께 제시해 주세요.

4. 담백한 말투로 정리하기
- ‘단계별로 막힘없이 몰입해요’, ‘오늘의 생각하는 힘을 기르는 첫걸음’, ‘지능정보사회를 이끄는’ 등 홍보 문구를 제거해 주세요.
- 수업 시연 설명: ‘설명과 예시로 익히고, 퀴즈로 확인한 뒤 직접 해봐요.’
- 이어하기 설명: ‘지난 시간에 하던 활동을 다시 열어 보세요.’
- 학생 공간: ‘이번 수업과 지난 활동을 확인해요.’
- 교사 공간: ‘반별 수업을 열고, 이번 수업을 지정해요.’
- 제목은 ‘정보 수업을 위한 온라인 교실’, 마무리는 ‘내 교실로 들어가세요’를 유지해 주세요.

5. 화면의 일관성 확인하기
- 한국어 제목·본문의 글꼴은 Pretendard를 우선하고 한국어 sans-serif를 fallback으로 사용해 주세요.
- 기존에 추가된 ‘교육과정 안내’, ‘학습 모듈’, ‘교사용 가이드’와 모바일의 ‘커리큘럼/실습실/내 학습’ 등 새로운 메뉴는 제거해 주세요. 필요한 탐색은 현재 공개 홈 안의 구간 이동으로만 구성해 주세요.
- 상단의 ‘교실 입장’을 유지하고 읽기 쉬운 대비, 키보드 초점, 44px 이상의 조작 영역을 확인해 주세요.
- 움직임 줄이기에서는 설명과 단계 선택을 그대로 사용할 수 있게 해 주세요.

수정 완료 후 반영한 항목과 정적인 시안만으로 확인할 수 없는 동작을 짧게 알려 주세요. 새로운 기능이나 디자인 방향을 추가하지 마세요.
```
