## 최신 대화 인수인계 (2026-09-26)

- 먼저 [PRD의 새 작업환경·학생 홈 합의](../PRD.md#2026-09-26-합의-새-작업환경과-학생-홈)를 읽습니다. 오늘은 설치·구현보다 환경과 제품 방향을 대화로 구체화했습니다.
- 확정 방향: 로그인 후 본인 대시보드, 교사가 반별로 수동 지정한 이번 수업 우선, 반 전체에 수업 열기, 이미 열린 수업의 자유로운 복습, 첫 버전 공지 없음. 교사의 수업 내용 편집은 장기 아이디어입니다.

- Next.js·TypeScript·Tailwind·shadcn/ui는 추천 후보이며 아직 설치하거나 전환하지 않았습니다. Context7도 활용 방향만 논의했습니다. V1 기술 제약을 완화하는 문서 전면 개편 요청은 남아 있으나, 선생님이 환경 논의를 먼저 하도록 순서를 정했습니다.

- Figma: 처음 계정 확인 도구가 `Unknown tool`로 실패했으나 앱 재시작 후 정상 응답했습니다. 계정 donghyunt, 팀 역할 admin, 플랜 student, 좌석 View로 반환됐습니다. 파일별 읽기와 생성·편집 권한은 미검증입니다. 브라우저 로그인과 MCP 연결은 별개입니다. 계정 이메일은 문서에 기록하지 않습니다.
- 다음 대화에서는 기본 환경 조합을 정리하고 남은 중요한 선택만 구체화한 뒤, CS Class 전용 핵심 문서 개편과 대표 화면 시안으로 이어갑니다. 현재 앱 코드는 그대로입니다.

[PRD의 시각 방향 재검토](../PRD.md#시각-방향-재검토-2026-09-25)를 먼저 읽으세요. 기존 시안의 계정 교체 가상 상태에는 이전 작업 분리 오류가 있어, 디자인 확정 전 실제 계정 설계에 재사용하지 마세요.

### 최신 학생 홈 검토안 (2026-09-25)

- Google Stitch 프로젝트의 최신 후보는 **학생 홈 · 즐거운 정보 교실 (분기·반복 순서도 시안)**입니다. 이전 개선안의 밝고 단정한 스타일에 순서도 미리보기, 네 단계 진행 흐름, 저장·제출 상태를 정돈했습니다.
