# 완료 계획 원문 (2026-11-01)

2026-11-01 함수 수업(`functions`, 「나만의 명령, 함수」)을 구현하며 `docs/plans/`에서 뺀 완료 계획 1개입니다. `git mv`로 옮겨 내용은 바꾸지 않았고, 원래 경로·바이트·sha256은 [manifest.json](manifest.json)에 있습니다(바이트·해시는 Git에 저장된 LF 기준).

- `functions-lesson.md`: §1~§13은 Codex·Gemini(agy)와 합의하고 사용자가 승인한 설계(도입 비트 만들기, 개념·퀴즈·미션, 앱 구현 범위), §8.1에 엔트리 함수 사전 확인 결과, §13에 설계 검토 기록, §14에 7개 과제의 구현 계획이 있습니다.

계획의 "진행 중", "확인하지 않은 값" 같은 표현은 당시 문맥이며 현재 지시가 아닙니다. 구현 중 바뀐 결정(QA에서 더한 이탈 확인·저장된 방향 채점·함수 id 규칙 등)은 계획에 다시 적지 않았습니다. 현재 기준은 [PRD §4.1.4](../../../PRD.md#414-정규-수업-나만의-명령-함수)와 [개발 안내 §4.1](../../../DEVELOPMENT.md#41-entryjs-4023-실습-환경)을 따릅니다. 원문의 상대 링크는 원래 위치 기준이며 보관 위치에 맞춰 고치지 않았습니다.
