# 현재 문서 지도

CS Class는 독립적인 새 제품입니다. 현재 판단에는 아래 문서를 사용하고, V1의 과거 지침을 새 제약으로 적용하지 않습니다.

| 문서 | 역할 |
|---|---|
| [AGENTS](../AGENTS.md) | 에이전트 협업·자율성·안전·검증 원칙 |
| [INTENT](../INTENT.md) | 학생·교사에게 주고 싶은 경험 |
| [PRD](../PRD.md) | 기능의 합의·검토·구현 상태 |
| [DESIGN](DESIGN.md) | 시각 방향·참고 자료·시안 판단 |
| [TOOLING](TOOLING.md) | 추천 스택·실제 도구 연결·환경 준비 |
| [HANDOFF](HANDOFF.md) | 지금까지 한 일·남은 일·Git 작업 위치 |
| [CS Class 배포 기록](CS_CLASS_DEPLOYMENT.md) | 날짜·대상 버전별 시안 배포 근거 |
| [과거 기록 보관함](archive/README.md) | V1 원문과 CS Class 개편 전 문서 |

기능 결정은 PRD, 디자인 값은 DESIGN, 도구 설정은 TOOLING에 기록합니다. HANDOFF에는 다음 작업에 필요한 요약만 남겨 문서가 서로 다른 '현재'를 주장하지 않게 합니다. 대화의 새 결정은 그 상태(합의·제안·보류·구현·검증)에 맞춰 업데이트합니다.
