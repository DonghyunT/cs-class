# CS Class 제품 요구사항

갱신: 2026-09-26 · 초기 탐색 단계의 살아 있는 명세입니다. 대화에 따라 발전시키며, 합의된 방향과 현재 구현을 구분합니다.

## 제품과 첫 범위

**CS Class · 즐거운 정보 교실**은 독립적인 교실형 학습 서비스입니다. V1은 재사용 자산이며 새 제품의 구조적 제약이 아닙니다. 첫 실제 적용은 한 반의 일반 학습, 첫 모듈은 순서도 연구소를 출발점으로 합니다. 수행평가 이관은 별도 후속 논의입니다.

## 2026-09-26 합의한 경험 — 아직 새 화면에 구현되지 않음

| 영역 | 첫 버전 방향 |
|---|---|
| 공개 화면 | 배울 수 있는 주제와 예시를 둘러보며 호기심을 느끼는 공간 |
| 로그인 후 | 학생은 본인 학습 대시보드, 교사는 담당 반 관리 화면 |
| 학생의 주요 행동 | 마지막 활동보다 교사가 지정한 **이번 수업**을 먼저 안내 |
| 지난 활동 | 주요 수업 아래에서 이어하기 제공 |
| 이번 수업 지정 | 교사가 반별로 직접 지정. 바꾸기 전까지 유지 |
| 수업 공개 단위 | 반 전체. 학생별 보충·심화 배정은 초기 범위에서 제외 |
| 복습 | 해당 반에 이미 열린 수업은 자유롭게 탐색·복습 |
| 공지 | 첫 버전에서는 제공하지 않음 |
| 수업 내용 편집 | 교사 편집기는 장기 아이디어. 초기 구현에 포함하지 않음 |

밝은 바탕, 필요한 부분에만 쓰는 파란 강조색, 읽기 쉬운 글자와 단정한 구성을 시각 방향으로 합의했습니다. 최종 화면·템플릿 전체를 채택한 것은 아닙니다. [디자인 방향](docs/DESIGN.md)을 참고합니다.

## 기존에 논의한 기능 방향

아래는 CS Class 초기 시안 단계에서 논의한 요구입니다. 상세 구현 전에 재검토할 수 있으며 V1 코드를 그대로 옮겨야 한다는 뜻은 아닙니다.

### 학습

- 순서도 기호 설명과 개념 퀴즈 4문항, 순차·선택·반복·흐름 오류 해석 4문항, 흐름을 보여주는 불빛 시뮬레이터를 출발점으로 합니다.
- 실습은 라면·놀이기구·비밀번호·등교 예시·나만의 백지라는 기존 콘텐츠를 활용할 수 있습니다. 최종 화면 배치는 대표 시안에서 검토합니다.
- 열린 수업 안의 단계는 자유롭게 이동합니다. 퀴즈는 맞혀서 완료한 상태를 기록하는 방향이며 답안·점수·시도 횟수를 추가 수집하지 않습니다.
- 자유 설계에서는 학생이 조립·실행·수정을 주도합니다. 기존 논의는 현재 초안의 AI 설계 검사 통과 후 학생이 명시적으로 제출하는 방식입니다. 실제 AI·검사 기준·장애 흐름은 구현 전에 구체화합니다.

### 교실과 계정

- 학생은 반 코드·출석번호·개별 비밀번호로 들어가는 방향을 논의했습니다. 교사 인증·초대·계정 관리 절차는 아직 구체화가 필요합니다.
- 교사는 담당 반의 열린 수업, 학생 진행·제출 상태를 보고 마감·재개방합니다.
- 전입생 추가와 비밀번호 재발급은 기존 작업을 보존합니다. 같은 번호의 학생 교체는 새 식별자로 구분하고 이전 작업을 기록으로 분리하는 방향입니다.
- 인증 지속성과 작업 복구는 공유 PC에서 다른 학생에게 자료가 노출되지 않도록 함께 설계합니다.

### 저장·제출·기록

- 초안을 서버에 자동 저장하고 저장·실패·복구 상태를 명확히 표시합니다. 실패해도 작성 내용은 유지합니다.
- 제출본은 초안과 구분하여 보존하고, 마감 전 재제출 및 이전 제출본 조회를 지원하는 방향입니다. 초안 변경 후 이전 AI 검사 결과를 그대로 사용하지 않습니다.
- 연도·반·번호로 지난 기록 조회와 내보내기를 검토합니다. 자동 삭제 시점을 두지 않는 초기 구상이 있으나 실제 보관·삭제 정책은 학교 규정 확인과 협의 후 확정합니다.
- V1의 답안·확정 성적을 이 작업에서 이관하지 않습니다. 실제 자료 변경은 원본·영향·복구 범위를 별도로 정합니다.

## 현재 구현과 검증의 경계

| 항목 | 현재 사실 |
|---|---|
| 프런트엔드 | web/의 HTML·CSS·Vanilla JS 가상 시안 |
| 화면 흐름 | 공개·학생·교사 홈, 개념·응용 퀴즈, 5단계 클릭 실습, 가상 제출·마감·계정·기록실 |
| 저장 | sessionStorage에 탭 한정 가상 상태 |
| 미구현 | 실제 인증, 서버 저장, AI 검사, 실제 제출, 자유 연결 순서도 캔버스 |
| 알려진 문제 | 가상 학생 교체 시 이전 작업 분리 오류. 실제 계정 설계에 그대로 재사용하지 않기 |
| 새 합의 | 이번 수업 지정·새 대시보드·새 시각 방향은 미구현 |

2026-09-25 기록에는 로컬 공개→학생→퀴즈 오답·재시도→실습→가상 제출, 교사 가상 계정 중복 차단·마감, 390px 화면과 콘솔 오류 0건 확인이 있습니다. 전체 키보드 흐름, 창 폭을 연속 변경하는 점검, OS 움직임 줄이기 설정 검증은 남아 있습니다. 저장 실패 처리는 sessionStorage 예외 처리만 확인한 것으로 서버 장애 검증이 아닙니다. 이번 문서 개편에서는 앱 검사를 다시 실행하지 않았습니다. [시안 배포 기록](docs/CS_CLASS_DEPLOYMENT.md).
