## 대시보드 파일럿 구현과 로컬 검증

- 학생·교사 첫 화면은 작은 이번 수업·내 할 일·실제 수업/제출 기록의 다음 행동·다가오는 일정입니다. 학생의 전체 수업·필터·진행·이어하기·복습은 `/student/lessons`, 교사의 수업 공개/이번 수업은 `/teacher/classes`, 학생 진행/제출/계정은 `/teacher/students`로 옮겼습니다. 기존 학습·제출·EntryJS 저장과 이동 보호는 유지합니다.
- 내 할 일은 체크박스·한 줄 입력·인라인 수정·완료/해제·삭제를 지원합니다. 빠른 Enter·IME·Tab/Space·Esc와 저장 뒤 초점을 처리합니다. 반 일정은 제목·한국 날짜·선택 수업 연결의 간단한 목록입니다. 교사·강사 담당 반 수정과 학생 본인 반 조회를 서버 세션으로 검사하고 직접 Firestore 접근은 차단합니다.

## 다른 PC에서 이어가기

1. [개발 안내](DEVELOPMENT.md#다른-pc에서-시작)에 따라 Git·Node 24·Java 21+를 준비합니다. 현재 `codex/dashboard-pilot-brief`의 미커밋 소스·문서·이미지를 먼저 보존합니다. 깨끗한 main에서 새 작업을 시작하기로 정한 경우에만 `git fetch origin`·`git pull --ff-only`로 갱신하고 새 `codex/` 브랜치를 만듭니다.
2. 저장소 루트에서 `npm ci`와 최초 `npx playwright install chromium`을 실행합니다. EntryJS 자산은 자동 준비됩니다. Java·브라우저·플러그인·인증·캐시는 PC별이며 이 PC의 `scratch/tools/java/`는 Git으로 전달되지 않습니다.
3. `npm run dev:emulator`를 실행합니다. 엔트리봇 실습의 강사/학생 확인 방법은 [EntryJS 개발 안내](DEVELOPMENT.md#entryjs-실습)를 따릅니다. 실제 Firebase 개발이 필요할 때만 본인이 관리하는 안전한 경로로 환경파일·관리자 인증을 준비합니다.
4. 다음 요청 예시: “AGENTS.md와 docs/HANDOFF.md를 읽고 `codex/dashboard-pilot-brief`의 미커밋 자료를 보존하자. 구현한 대시보드 파일럿과 이번 로컬 검증 결과를 확인하고 다음 범위를 정하자.” 최신 main만 받으면 미커밋 파일럿이 빠지므로 소스·검사·문서·이미지 전달 상태도 확인합니다. 커밋·push·병합·배포는 해당 요청이 있을 때 진행합니다.
