# 교사 수동 갱신·손들기 일시 중지 계획

작성·갱신: 2026-10-14 · 상태: 구현·압축 검증 완료, `main@a3ad309`에 반영(원격·운영 상태는 [HANDOFF](../../HANDOFF.md#현재-작업-상태))

**목표:** 교사의 실제 수업 운영에 맞춰 불필요한 자동 조회를 없애고, 손들기를 복구 가능한 상태로 잠시 중지합니다.
**접근:** 기존 `codex/firestore-read-optimization`의 미커밋 변경 위에 최소 수정합니다. 새 의존성·관리자 설정 화면·캐시 서비스는 추가하지 않습니다.
**실행:** 구현 요청 시 `superpowers:executing-plans`로 순서대로 진행합니다.
**정책 근거:** [PRD](../../PRD.md), [검증 안내](../../DEVELOPMENT.md), [이전 최적화와 측정](2026-10-14-firestore-read-optimization.md).

## 1. 손들기를 한 곳에서 끄기

- [x] `src/lib/classroom/features.ts`에 공유 설정 `CLASSROOM_HELP_ENABLED = false`를 둡니다. 클라이언트와 서버가 같은 코드 설정을 사용하며, 복구는 설정 변경 후 재빌드·배포로 수행합니다.
- [x] 학생의 `HelpButton`, 교사의 `HelpRequests`와 손든 학생 수·이동 링크를 조건부 렌더링합니다. CSS로 숨기는 대신 컴포넌트가 마운트되지 않게 하여 최초 조회와 타이머를 모두 없앱니다.
- [x] `src/app/api/classroom/[...path]/route.ts`의 GET·POST에서 모든 `help` 경로를 Firestore 접근 전에 `403 / HELP_DISABLED`로 차단합니다. 구버전 화면·직접 호출도 읽기와 쓰기를 유발하지 않게 합니다.
- [x] 손들기 구현·검사·기존 기록은 보존합니다. 기존 요청·snapshot을 삭제하거나 상태 변경하지 않습니다.

대상 화면: `src/components/student/lesson-shell.tsx`, `src/components/dashboard/dashboard.tsx`, `src/components/teacher/dashboard.tsx`. 손들기 컴포넌트와 서버 구현은 복구를 위해 남깁니다.

**시각 기준:** 손들기 컴포넌트와 전용 래퍼를 제거하면 헤더·대시보드가 기존 Flex/Grid 흐름에 따라 불필요한 빈자리 없이 재배치되도록 합니다. 대체 플레이스홀더·안내 배너는 신설하지 않고 구두 안내를 기본으로 합니다. 조건부 렌더링만으로 처리하는 것을 우선하되, 실제 화면에서 문제가 확인될 때만 최소 CSS 수정합니다.

## 4. 기대효과와 복구·배포 조건

이전의 하루 4반×27명×45분·교사 담당 반11개·도움 대기 없음 모형에서, 교사 과제 자동 조회 약 11,880회와 학생/교사 손들기 정기 조회 약 15,300회를 제거합니다. 남는 정기 읽기는 **약 56,700 → 29,520회**이며 최초 진입·수동 갱신·저장·채점·재시도는 별도입니다. 실제 과금·하루 4만 회 이하 달성을 보장하는 수치가 아닙니다.

- 손들기 비활성 동안에는 관련 쿼리가 실행되지 않으므로 손들기 복합 인덱스 배포가 이번 앱 반영의 선행 필수 조건은 아닙니다. 인덱스 구성은 보존합니다.
- 복구 전에는 기존 대기 요청이 오래된 요청인지 확인하고 처리 기준을 결정합니다. 승인 없이 운영 기록을 정리하지 않습니다. 인덱스 준비 완료·활성 모드 검사 확인 후 설정을 켠 앱을 배포합니다.
- 후속 구현 요청에 따라 로컬 변경을 완료했고 사용자 승인으로 로컬 커밋에 정리했습니다. 이 구현 단계에서는 푸시·배포·운영 기록 변경을 하지 않았으며, 이후의 `main` 반영과 배포 상태는 [HANDOFF](../../HANDOFF.md#현재-작업-상태)에 기록합니다.

## 5. 실제 검증 결과

- 사용자 요청에 맞춰 관련 17개만 새 demo·프로덕션 빌드에서 실행했고 모두 통과했습니다(1.1분). 손들기 API 차단·기록 보존·화면/요청 제거, 교사 세 화면 수동 갱신, 학생 안내, 느린 응답 중 반 전환, 수동 저장, 등록 수업 스모크, 교사 변경 충돌·대화상자, 사용량 측정을 포함합니다. 전체 E2E와 비활성 중인 손들기 검사는 실행하지 않았습니다.
- 프로덕션 빌드·린트·타입·문서 검사 통과. 단위/정책 검사는 1차의 동일 서버 로직·정책 결과를 재사용했으며 이번 단계에서 반복 실행하지 않았습니다.
- 390/768/1440px 학생·교사 화면의 가로 넘침 검사와 대표 스크린샷 확인을 완료했습니다. 별도 CSS·배너·플레이스홀더 없이 기존 흐름으로 재배치됩니다.
- 10분 가상 시간의 손들기 요청·교사 현황 반복 조회는 0회, 학생 반 설정 조회는 20회였습니다. 초기 조회는 별도 기록했습니다. 위 29,520회는 세션/활동을 포함한 문서 읽기 모형이며 실제 과금 측정이 아닙니다.
