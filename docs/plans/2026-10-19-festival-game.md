# 축제 미연시 완성도 개선 계획

> 실행: root가 구현하고 Luna max 리뷰어 3명은 서사·UX·학습 관점의 읽기 전용 검토만 합니다. 사용자는 계획부터 구현·검증·공개 준비까지 자율 진행, 마지막 실제 공개 직전 승인만 요청했습니다.

## 목표와 범위

처음 초대부터 다음 날의 약속까지 하나의 게임으로 이어지고, 선택과 개념 활동의 결과를 하루가 자연스럽게 받아 주도록 합니다. 기존 독립 HTML 구조·3챕터·27장면·차시별 중심 활동 3개를 유지합니다. 확장은 목차에서만 엽니다. 로그인·학생 저장·DB·수업 목록·의존성·운영 설정은 바꾸지 않습니다.

기존 전용 브랜치 `feat/festival-romance-lessons`와 PR #59를 이어 씁니다. 현재 미커밋 이미지·문서는 이 대화의 작업이므로 보존하고 포함합니다. 별도 작업 트리와 새 리뷰어를 반복 생성하지 않습니다. 기존 운영 사이트의 `/festival-romance.html` 정적 파일로 공개 준비하며, 다운로드용 HTML과 동일한 내용을 사용합니다. 실제 main 병합·공개는 최종 승인 후입니다.

## 함께 결정한 방향

- 서사: 첫 승낙을 플레이어 선택으로 만들고 마지막 다음 날 약속은 유지합니다. 공개 안내판의 개인 입장 기록은 개인 앱 메시지로 바꾸되, 하루가 일찍 도착한 배려의 회수는 남깁니다.
- 선택: 이름·날씨·기념품·카드의 단일 선택은 태도가 다른 두 선택으로 바꿉니다. 같은 활동을 실행하되 `flow.choiceReplies`로 선택을 받아 주고, 기존 결과 대사는 반드시 유지합니다. 간결 모드에서는 결과 대사를 우선합니다.
- 학습: 두 AND 조건이 모두 거짓일 때 두 이유를 모두 설명합니다. 보유 입장권 6장의 출처를 앱에 짧게 보여 줍니다. 될 때까지 반복과 부정 조건 while의 관계를 정확히 설명합니다. 새 활동·점수·인벤토리는 만들지 않습니다.
- UX: 다음 동작은 하단 버튼 하나로 통일합니다. 정리 화면에서는 명시적인 다음 챕터 버튼을 제공하고 교사가 실습·휴식을 선택할 수 있게 합니다. 기억 삭제 뒤 죽은 이어보기 버튼과 기념품 화면 잘림을 고칩니다.
- 그림: 승인한 남녀 6표정과 v5 수줍음을 투명 가장자리·동일 프레임·얼굴 위치로 맞춥니다. 대사 감정에 따라 표정을 배치하고 내 말·생각 중에는 직전 하루 표정을 유지합니다.

- [x] 네 단일 선택에 다른 태도와 결과 뒤 짧은 반응을 연결합니다. `choiceReplies`가 결과 반응을 덮지 않게 합니다.
- [x] 개인 도착 메시지와 엔딩 회수, 세 도형의 동등한 설렘, 기념품 후속 연결을 맞춥니다.

### 2. 진행·표정·화면

- [x] 기억 삭제 직후 이어보기 UI를 갱신하고 이어보기는 장면 처음부터임을 알립니다.

## 리뷰에서 유의할 경계

- 간결 모드가 선택 반응만 남기고 실제 결과를 잘라내지 않아야 합니다.
- 입력을 바꾸면 기존 결과가 무효화되고 다시 실행해야 합니다.
- 네 AND 조합과 세 도형 모두 대사와 실행 결과가 맞아야 합니다.
- 표정 전환으로 얼굴 크기·위치가 튀거나 옆 프레임이 보이면 안 됩니다.
- 오프라인 열기와 웹 공개 파일의 동작이 같고, 실제 학생 자료·운영 API를 사용하지 않아야 합니다.

## 진행 기록

- 계획: 세 리뷰어의 현재 소스·기존 화면 검토를 합쳤습니다. 학습 리뷰어의 엔딩 수위 완화 제안은 현재 사용자의 게임 목표에 맞춰 제외했고, 리뷰어 간 논의에서도 개념상 이유가 없음을 확인했습니다.
- 실행 방식: 기존 브랜치에서 root 직접 구현, 같은 세 리뷰어 재사용, 변경 경로 중심 검증. 최종 공개 전 승인 조건은 유지합니다.

- 구현·검토 완료: 단위/패키지 24개, Chrome 17묶음, 정책20·문서2개, lint·typecheck·build·문서·diff 검사 통과. 모바일 도입 카드 가림은 별도 실패 재현 후 수정·통과했고 같은 UX 리뷰어가 최종 캡처에서 확인했습니다.
- 선택한 절충: 간결 모드는 활동 결과만 우선합니다. 첫 초대의 두 답이 같은 축제 동선으로 수렴하는 것은 유지합니다. 새로운 분기 시스템이나 플레이 모드는 추가하지 않았습니다.
