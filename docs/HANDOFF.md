# 이어갈 작업

갱신: 2026-09-27

## 현재 위치

- 브랜치 `codex/platform-ui`. 문서 통합·새 플랫폼·디자인 개편을 로컬 체크포인트 커밋으로 보존했습니다(`git log -1`로 확인). 원격 푸시·병합·배포는 하지 않았습니다.
- 새 앱 `platform/`: 공개 홈, 학생·교사 로그인 시안, 필수 비밀번호 변경, 학생 홈, 교사 반 선택·수업 설정·학번 검색·초기화 확인창을 구현했습니다. 강사 범위는 10·11반입니다.
- 디자인 개편: 홈에 생각 놀이터·스크롤에 반응하는 배움의 과정·역할별 미리보기·입장 안내를 구성했습니다. 학생 홈은 이번 수업·교실 요약·전체/둘러본 수업 필터·최근 활동 순입니다. 공통 글꼴은 로컬 Pretendard이며 움직임 줄이기, 작은 화면과 메뉴 초점 복구를 지원합니다.
- 가상 데이터만 메모리에 유지합니다. Google 버튼은 화면 체험이며 실제 OAuth가 아닙니다. 새로고침 시 초기화됩니다. 콘텐츠 3개도 화면 구성용 예시입니다.
- 기존 `web/`과 V1 보관 자료는 그대로 유지합니다. 외부 환경을 변경하지 않았으며 기존 Vercel 배포 루트는 기록상 `web/`입니다.
- 학생 등록 엑셀은 2학년 1~11반 각 27명으로 준비되어 있습니다. Firebase 계정은 생성하지 않았습니다. 제품·계정 합의는 PRD를 참고합니다.

## 다음에 시작할 때

- 먼저 이 문서와 [PRD](../PRD.md)를 읽고 현재 브랜치·작업 트리를 확인합니다. 기존 앱을 이어서 수정합니다.
- 로컬 개발 서버는 종료했습니다. 저장소 루트에서 아래 명령으로 다시 실행한 뒤 `http://127.0.0.1:3000`을 엽니다. 의존성이 없으면 먼저 `npm --prefix platform ci`를 실행합니다.

```powershell
npm --prefix platform run dev -- --hostname 127.0.0.1 --port 3000
```

- 체험 계정과 실행 안내는 [README](../README.md), 저장된 비교 화면은 [공개 홈](../outputs/design-review/home.png)·[학생 홈](../outputs/design-review/student.png)에 있습니다. 브라우저의 가상 계정·수업 설정은 다시 체험하면 됩니다.
- 학생 계정 엑셀은 로컬 파일로 보존하고 Git에서 제외합니다. 저장소만 복제하면 해당 엑셀은 따라오지 않습니다.

3. 명단 등록 스크립트, 비밀번호 변경·초기화, 새로고침·공유 PC 세션을 실제 가상 계정으로 검증합니다. 수업 내용은 이후 채웁니다.

## 검증 범위

- 2026-09-27 로컬에서 Next.js 배포용 빌드, ESLint, TypeScript, Playwright 6개 시나리오가 통과했습니다. 화면 폭 320·390·768·1024·1440px을 확인했습니다. CI 설정은 추가했지만 원격 CI는 아직 실행하지 않았습니다. 현재 문서의 로컬 링크와 `git diff --check`도 확인했습니다. 자동 테스트는 공개 화면·오류·필수 비밀번호 변경·초기화 후 기록 보존·반별 수업 반영·강사 범위·빈 상태·모바일·키보드 초점·스크롤 이야기·미리보기 전환·모션 제어·수업 필터를 다룹니다.
- 실제 인증·서버 권한·데이터 보존·외부 서비스는 검증 대상에 포함되지 않습니다. 현재 UI의 역할 구분은 보안 경계가 아닙니다.
