## 다른 PC에서 이어가기

1. HEAD·브랜치·기존 차이를 먼저 확인하고 기록을 보존합니다. 진행 중 작업이 있으면 위 [현재 작업 상태](#현재-작업-상태)의 브랜치로 `git fetch origin` → `git switch <브랜치>` → `npm ci` 순서로 이어 갑니다.
2. Node 24·Java 21+·Chromium 준비는 [개발 안내](DEVELOPMENT.md#다른-pc에서-시작)를 따릅니다. 기본 `dev:emulator`는 시드를 다시 쓰므로, 기존 기록이 있으면 먼저 export하고 [시드 없는 복원](DEVELOPMENT.md#기존-demo-기록을-복원해-보기)을 씁니다.
3. Git은 코드·검사·문서만 전달합니다. 비밀 설정·관리자 키·로컬 기록·`scratch/`는 비공개 경로로 따로 옮깁니다. 운영 계정·명부는 [서버 안내](FIREBASE_SETUP.md#승인된-운영-테스트-계정)·[명부 절차](DEVELOPMENT.md#실학생-명부-준비와-반별-발급)를 따릅니다.
4. 이 PC의 demo 기록 복원 기준은 Git 제외 `scratch/release-20261013/demo-before-ci-debug/`입니다(반 11개·작품 4개). 이후 체험 기록은 새 export로 보존하며, 이 export가 항상 최신이라고 가정하지 않습니다.
