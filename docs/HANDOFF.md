## 이번 UI 개선의 경계

기존 색·글꼴·학습 완료 기준·DB 계약·외부 호출/예약을 유지합니다. `submissionCountFor`는 제출 학생과 최신 미션 작품 수를 구분하고, 선택 평균 도전은 기본 네 미션 완료에서 제외합니다. 자동 저장·검증 통과·제출 저장 성공은 별도 상태이며 수정 중에도 이전 제출본/완료는 보존합니다.

루프 엔지니어링은 작은 변경·대상 검사·독립 검토·필요한 수정 순서로 적용합니다. 최종 공통 화면 변경을 통합할 때 lint/build/전체 E2E를 집중 실행합니다. 담당 파일·합의·결과를 작업 장부와 지시서로 전달하며 새 의존성과 범용 상태 관리 모듈을 추가하지 않습니다. 개발용 화면/장부는 Git 제외 `scratch/ui-refinement-2026-10-05/`에 있습니다.
