# CS Class 인수인계

갱신: 2026-09-26 · 지금 이어갈 작업의 요약입니다. 과거 전체 기록은 [문서 보관함](archive/README.md)에 있습니다.

## 지금 어디까지 왔나

CS Class는 V1의 확장판 의무에서 벗어나 독립적인 새 제품으로 설계합니다. 선생님은 '환골탈태' 수준의 새 출발과 외부 라이브러리·스킬을 적극 활용하는 탐색을 원합니다. 보안·데이터 무결성과 실제 사용성은 지키되 초기 문서를 강한 금지 목록으로 만들지 않습니다.

이번 요청으로 AGENTS를 포함한 핵심 문서를 전면 재작성하고, V1 기록과 CS Class 이전 시안 기록을 분리 보존했습니다. 직전 대화에서 로컬 수정했던 PRD·DESIGN·HANDOFF도 원본 스냅샷에 포함했습니다. 이후 요청으로 V1 코드·설정을 보관 영역에 이동했습니다. 현재 web/ 시안과 클라우드 데이터, 설치 상태는 바꾸지 않았습니다.

## 오늘의 합의

- 공개 화면은 탐색과 호기심, 로그인 후에는 본인 대시보드입니다.
- 학생에게 교사가 지정한 이번 수업을 먼저 보여줍니다. 교사가 반별로 수동 지정하며 변경 전까지 유지합니다.
- 수업은 반 전체에 열고 이미 열린 수업은 자유롭게 복습합니다. 첫 버전은 공지 없이 출발합니다.
- 교사의 수업 내용 편집은 장기 아이디어이며 당장 구현하지 않습니다.
- Purity의 구성·조작감은 좋지만 민트색은 비선호입니다. 교사 제공 LMS 이미지처럼 밝은 바탕에 필요한 곳만 파란색을 쓰는 방향과 가독성을 선호합니다.
- Next.js·TypeScript·Tailwind·shadcn/ui는 추천 조합으로 논의했으며 아직 설치·전환하지 않았습니다. Context7 적극 활용에도 긍정적이며 연결은 아직입니다.
- Figma는 앱 재시작 후 계정 확인이 성공했습니다. 파일별 읽기·편집 검증은 남았습니다. 자세한 연결 기록은 [TOOLING](TOOLING.md)에 있습니다.

선생님은 기술 이름을 스스로 고르기보다 에이전트가 수석 개발자 역할로 추천하고 쉬운 사용 장면을 질문하며 함께 구체화하기를 원합니다. 질문은 하나씩, 합의한 결정은 반복해서 묻지 않습니다. 실제 결과를 보여주며 발전시킵니다.

## Git과 실제 구현

- 준비 단계 종료 기준은 main입니다. 선생님이 2026-09-26 V1 보관 정리와 main 병합·푸시를 명시적으로 요청했습니다. 기존 PR #1을 통해 통합하며 다음 대화에서는 원격 main을 확인한 뒤 새 목적의 codex/ 브랜치를 만듭니다.
- 원격: 비공개 https://github.com/DonghyunT/cs-class. V1 원본 출발점은 98781bd, 문서 개편 커밋은 6eb9595입니다. 개편 전 CS Class 시안은 cs-class-prototype-2026-09-26 태그(11bbb9c)로 보존했습니다.
- V1 코드·Firebase 설정·전용 검사·운영 도구·감사 근거 308개는 archive/v1/에 원문 보존했습니다. 보존 목록은 archive/manifest.json입니다. 예전 문서는 docs/archive/에 있습니다. 백업용/과 Git 제외 비밀 파일은 건드리지 않았습니다.
- web/은 기존 HTML·CSS·Vanilla JS 가상 시안 그대로입니다. 실제 인증·서버 저장·AI 검사·자유 연결 캔버스는 없으며 가상 학생 교체 시 이전 작업 분리 오류가 기록되어 있습니다.
- Vercel은 현재 시안을 유지합니다. main 병합으로 자동 배포가 발생할 수 있지만 실제 학생 운영판이나 Firebase 연결을 뜻하지 않습니다. 배포 상태는 해당 병합 커밋으로 확인합니다.
- 새 Next.js 앱이나 새 디자인은 아직 만들지 않았습니다. V1은 보관 자료이며 새 기술 선택을 제한하지 않습니다.

## 다음 순서

1. 새 문서를 기반으로 개발 환경 조합을 정리하고 채택·설치 범위를 구체화합니다. 기존 V1 기술 제한을 다시 전제로 삼지 않습니다.
2. 이번 수업 미지정·수업이 없는 상태 등 대표 화면에 필요한 남은 선택을 짧게 논의합니다. 세부 간격·색상 수치는 에이전트가 시안으로 제안합니다.
3. 실제 한국어 학생 홈 대표 시안을 만들고 피드백으로 다듬습니다. 그 뒤 다른 화면으로 확장합니다.
4. 분리된 개발 환경에서 가상 계정으로 인증·저장·권한·제출·복구를 검증하고, 학생 자료 투입 전에 보관·운영 절차를 확정합니다.

## 이번 문서 작업의 검증

2026-09-26 로컬 작업 트리에서 보존 문서 36개의 SHA-256 일치와 Git에서 추출한 원문의 바이트 일치를 확인했습니다. 현재 문서·보관함 안내의 로컬 링크 44개가 유효하고, git diff --check도 통과했습니다. 보관함 내부에는 자동 적용되는 이름의 AGENTS.md가 없습니다. 역사 문서 본문의 링크는 당시 경로를 그대로 보존했습니다.

변경은 문서와 보존 메타데이터에 한정됩니다. 보관함의 .gitattributes는 다른 PC에서도 원문 바이트를 유지하도록 줄바꿈 자동 변환을 해제합니다. 앱 코드가 바뀌지 않아 앱 테스트와 수동 배포는 수행하지 않습니다. 후속 요청에 따른 푸시와 자동 Preview 결과는 Git 원격 및 Vercel의 해당 커밋 상태로 확인합니다.
