## 현재 실행과 환경

새 앱은 `platform/`에 있습니다. Node.js 24와 npm을 사용합니다.

```powershell
cd platform
npm ci
npm run dev
```

[로컬 앱 열기](http://localhost:3000/). 검증 명령은 AGENTS.md에 있습니다.

- 공개 홈, 학생·교사 입장, 첫 비밀번호 변경, 학생 홈, 반별 수업 설정과 학생 비밀번호 초기화를 체험할 수 있습니다. 강사는 10·11반만 관리합니다.
- **화면 체험용 시안:** 가상 계정과 변경 사항은 메모리에만 유지하며 새로고침하면 초기화됩니다. Firebase 인증·서버 권한·저장·실제 수업 콘텐츠는 미구현입니다.
- 체험 계정: 학생 `20101` / `class-demo`, 빈 교실 학생 `21101` / `class-demo`. 강사 비밀번호 `teacher-demo`. 교사 화면은 Google 로그인 체험 버튼으로 들어갑니다. 실제 비밀번호를 입력하지 않습니다.
- 디자인: 홈의 생각 놀이터·스크롤 이야기·학생/교사 공간 미리보기, 학생 대시보드의 수업 필터를 제공합니다. 한국어 글꼴 [Pretendard 1.3.9](https://github.com/orioncactus/pretendard)은 로컬 제공하며 [SIL OFL 라이선스](platform/src/app/fonts/OFL.txt)를 포함합니다.
- **채택 기술:** Next.js + TypeScript + Tailwind CSS + shadcn/ui. 의존성과 정확한 버전은 `platform/package.json`과 잠금 파일에 있습니다.
- 기존 `web/` 시안은 보존했습니다. 필요할 때 `python -m http.server 8765 --bind 127.0.0.1 --directory web`으로 실행합니다.
- **외부 환경 기록(2026-09-26):** Vercel `cs-class`의 배포 루트는 `web/`. main 병합 시 자동 배포될 수 있습니다. Firebase 후보 `cs-class-f74c4`는 미연결이며 별도 개발 환경도 준비 전입니다. 연결 시 실제 대상을 재확인합니다.
- **도구 기록(2026-09-27):** Figma 계정과 Designo 원본 스크린샷 조회를 확인했습니다. Figma 파일 편집은 미검증입니다. Context7은 활용 방향만 논의했으며 연결 전입니다. 사용 시 가용성을 확인하고 버전에 민감한 내용은 공식 문서로 검증합니다.

## 함께 작업하는 방식

선생님은 원하는 수업 경험을 설명하고, 에이전트는 개발·디자인·교육공학 관점에서 대안과 이유를 쉽게 제안합니다. 선생님께는 격식체로 설명하며 중요한 질문은 하나씩 묻습니다.

작업마다 목적과 완료 기준을 짧게 정리하고, 합의한 범위에서 실행 → 검증 → 수정을 반복합니다. 같은 실패가 반복되면 접근을 바꾸며, 기준을 충족하면 마무리합니다. 복잡한 분기·의존성이 있을 때만 그래프로 정리합니다. 이 방식은 개발 협업에 적용합니다.

되돌릴 수 있는 세부 작업은 자율적으로 진행하되, 제품 방향·전체 기술 전환·비용·실제 데이터와 접근 범위 변경은 협의합니다. 제품 결정은 PRD, 이어갈 상태는 HANDOFF에 한 번만 기록합니다.

[과거 문서와 재사용 자산](docs/archive/README.md)은 필요할 때만 참고합니다.
