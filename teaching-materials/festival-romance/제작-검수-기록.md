## 게임 흐름·6표정 적용 추가 검수

Luna max 3명이 서사 플레이어·UX 플레이어·정보교사 관점에서 현재 소스와 기존 화면을 먼저 읽고 계획을 함께 정했습니다. 모두 읽기 전용이었으며 구현·검사·커밋 준비는 root가 맡았습니다. 수정 중 교사의 첫 답장과 전송 사건 구분, 간결 모드의 도착 대사 누락, 결과 대사를 지우지 않는 선택 반응 구성을 주고받고 고쳤습니다. 마지막에는 최신 화면과 소스를 같은 리뷰어들이 재검토했습니다.

변경: 초대 수락을 플레이어가 답하고 전송 활동은 별도 준비 완료 답장을 보냅니다. 네 본편 활동의 말투를 둘로 나누고 일반 모드에서 각 반응과 결과를 함께 보여 줍니다. 입장권 6장은 앱의 참여 선물로 밝히고, AND의 두 조건이 모두 거짓일 때 둘 다 설명합니다. 될 때까지와 부정 조건 while의 같은 흐름을 명시했습니다. 선택한 세 도형 모두 비슷한 무게의 따뜻한 반응을 받으며, 개인 채팅 도착 기록과 함께 만든 조명을 엔딩에서 회수합니다.

화면: 하단 진행 버튼 하나, 명시적 다음 챕터 이동, 저장 장면 다시 열기와 기억 삭제의 즉시 갱신, 1366×768 기념품 판단 버튼을 정리했습니다. 남녀 각각 6표정 v6는 512×1024 칸을 공유하며 내 말·생각 중에는 직전 하루 표정을 유지합니다.

이번 실행 결과: 단위/패키지 24개, Chrome 17개 묶음, lint·typecheck·Next Production build·문서 검사·diff 공백 검사를 확인했습니다. Chrome은 세 챕터 기본 진행, 네 AND 조합, 네 날씨 경로, 일반/간결 말투, 세 도형의 결과와 엔딩, 실제 타이머·모달 보류, 저장 이름 복원·기억 삭제, 키보드와 390px 이야기 선택을 포함합니다. 페이지 오류 0·외부 요청 0이며, 남녀 표정 비교 화면도 확인했습니다. 세부 실행 결과는 `qa/verified-report.json`에 둡니다.

로컬 Next Production 서버에서 공개 경로 `/festival-romance.html`의 200·HTML 응답과 내려받는 완성본의 SHA-256 일치를 확인했습니다. 공개 파일과 오프라인 파일은 동일 빌드가 생성합니다. 전체 사이트 E2E와 실제 학교 프로젝터·한글 입력기·학생 반응·수업 시간은 미검증입니다. main 병합과 운영 공개는 최종 사용자 승인 뒤 진행합니다. 이전 절의 검사 수와 외형은 각 당시 버전 기록입니다.

## 적용한 변경

- 한 HTML에 세 챕터·27장면을 유지했습니다. 확장 장면은 핵심 경로에서 생략합니다.
- 대화 선택→선택을 수행하는 활동→실행 결과를 받아 주는 대화로 연결했습니다.
- 답장 두 가지, 사진·게임 부스, 기념품 세 종류, 도형 세 종류가 실제 선택·입력·결과에 맞게 이어집니다.
- 약속 시각과 초대장 이름, 이동 경로, 기념품, 조명 모양을 이야기에서 사용하고 확정한 상태만 복원합니다.
- 후속 대사의 개념 낭독을 줄이고 자연스러운 문장과 다음 행동으로 정리했습니다.
- 변수 표시 불일치, 경품과 대사 불일치, 조명 끄기와 횟수 표시 혼동, 3회에서 모양 변경되던 문구를 수정했습니다.
- 도형의 이동·회전을 한 줄씩 나누고 방향 화살표와 실행 줄을 보여 줍니다. 조건 반복은 검사→질문/카드 열기도 단계별로 봅니다.
- 조건이 거짓이었던 경로와 방문하지 않은 경로를 구별합니다. NOT는 같은 우산 조건을 뒤집습니다.
- 입력/규칙 변경 시 이전 결과를 무효화합니다. 예측은 관찰 결과와 함께 표시하고, 실행 후에는 잠급니다.
- 목차·교사 메모·설정 모달이 열린 동안 자동 실행을 보류하고, 장면을 바꾸면 이전 타이머를 정리합니다.
- ‘10분 경로’를 ‘핵심 경로’로 바꾸고 확장 생략·도입/후속 대사 축약을 실제 적용했습니다. 수업 시간은 실측하지 않았습니다.

## 리뷰 운영과 반영

사용자가 지정한 기존 GPT-6 Luna · max 두 명을 재사용했습니다. 서사·대화와 개념·교실 운영을 분담했습니다. 초기 서사 초안 편집에 한 리뷰어가 참여했으나, 사용자의 검토 전용 지시 직후 중단했습니다. 이후 두 리뷰어는 파일을 쓰지 않고 의견만 전달했으며 root가 최종 대본·코드·문서를 수정했습니다.

학습·운영 검토에서 나온 모달 중 실행, 프로그램 표현 변경 후 옛 결과 사용, 조건 반복의 검사 단계 문제를 보완했습니다. 지도 활동의 완료 콜백 지적은 현재 지도에 flow가 없으므로 실제 복귀 차단 문제에 해당하지 않습니다. 지도는 목차에서 자유롭게 여는 확장으로 유지했습니다. 기억 삭제 뒤 새 기록이 생성되는 시점은 안내와 사용 설명에 명시했습니다.

서사 검토의 입장권 비교→운영 시작 조건 연결, 동적 명사의 조사, 답장 응답, 초대 문장을 마지막으로 정리했습니다. 데이터 변경 후 해당 부스 경로를 다시 확인했습니다.

학교 프로젝터의 실제 가독성, 물리 한글 입력기, 학생 반응, 10~15분 수업의 실제 진행 시간은 교실에서 확인해야 합니다. HTML은 약 15.3MB이며 외부 서버·배경음·음성을 사용하지 않습니다. 승인된 남녀 캐릭터와 교복의 작은 배지를 유지했습니다.


## 최종 개편 검수 (2026-10-19)

- 하루/나/생각/앱 알림을 별도 역할로 표시하고, 축제앱 채팅→초대장 기능→답장 사건의 관계를 명시했습니다.
- 이름 변경은 초대장 생성 즉시 전역 이름·이름표·설정·다음 저장에 반영됩니다.
- 기본 경로는 차시마다 활동 3개로 줄였습니다. 비교+AND, 경로+OR+NOT를 통합하고 나머지는 목차의 확장 활동으로 남겼습니다. 간결한 대화 설정은 대사 길이만 줄입니다.
- 실행 전 예상 질문을 별도 큰 카드로 배치했습니다. 선택 내용은 실행 결과와 비교하고, 입력 변경 시 다시 고릅니다.
- 준비팀과 점등식을 전날부터 예고하고, 공연 종료→점등식의 시간 흐름을 맞췄습니다.
- 캐릭터는 같은 의상을 유지한 청년 외형 v3로 교체했습니다. 생성 방식과 프롬프트는 image-generation-notes.md에 기록합니다.
- 기존 Luna max 검토자 2명이 서사/교실 운영을 읽기 전용으로 나눠 검토했습니다. 부스 운영 여부의 상태 전달, 경로 모델의 대기 분기, 단축 대사 속 약속 단서, 도형 선택 후 대사와 실제 구현의 일치를 보완했습니다.

현재 소스로 모델·상태·이야기·HTML 검사 **21개 통과**, Chrome에서 세 차시 전체 진행과 핵심 활동 3개씩을 포함한 **11개 검증 묶음 통과**입니다. 네 화면 크기(1366×768, 1280×620, 1920×1080, 390×844)의 가로 넘침이 없었으며 페이지 오류와 원격 요청은 0입니다. 이전 개편에서 확인한 타이머·저장 차단 등의 기록은 위 표에 구분해 보존했습니다. 최종 자료의 무결성과 재생성 결과는 함께 전달하는 검수 결과 파일에 기록합니다.

최종 저장소 패키지에서도 빌드·검사 21개와 브라우저 검사 11개 묶음을 통과했습니다. 실제 타이머의 일시정지·재실행·마지막 꺼짐, 교사 메모 중 보류 후 도형 완성도 현재 파일에서 확인했습니다. 저장소 문서 링크 검사 0오류, CI 정책·선별 범위·문서 검사 22개 통과입니다. 처음 임시 Git 생성이 샌드박스 권한으로 실패한 2개는 같은 검사를 정상 권한으로 재실행해 통과했습니다.
