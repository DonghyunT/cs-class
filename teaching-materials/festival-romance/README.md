# 내일, 축제에서 만나

중학교 정보 · 프로그래밍 개념 수업용 HTML입니다. 하나의 파일에 세 챕터, 총 27개 장면이 들어 있습니다. 확장을 포함한 수이며 모든 장면을 한 차시에 진행할 필요는 없습니다.

## 파일 열기

[`dist/festival-romance.html`](dist/festival-romance.html)을 내려받아 Chrome 또는 Edge로 여세요. 그림·스타일·코드가 내장되어 인터넷 연결이나 설치가 필요하지 않습니다. 다른 PC에는 HTML 하나만 옮겨도 됩니다. 저장소에서는 dist의 HTML을 완성본으로 사용합니다.

빌드는 웹 공개용 `../../public/festival-romance.html`도 같은 내용으로 생성합니다. 기존 사이트에 배포하면 `/festival-romance.html`에서 로그인 없이 열 수 있으며, 학생 계정·작품 저장·운영 DB를 사용하지 않습니다.

`qa/build-manifest.json`의 파일 크기·SHA-256도 빌드할 때 갱신합니다. 브라우저 검증 결과는 별도 `qa/verified-report.json`에서 확인합니다.

## 수업 흐름

**대화에서 내 답 선택 → 선택한 행동의 개념 활동 → 실행 결과 관찰 → 결과를 받아 주는 대화**로 진행합니다.

- 답장 말투를 고르면 그 문장이 활동의 작성창에 들어갑니다. 전송 버튼 사건을 실행하면 실제 문구에 대한 답장이 이어집니다.
- 사진·게임 부스를 고르면 각각의 입장 기준으로 보유 수를 비교합니다. 입장권 수와 운영 시작 여부를 함께 확인하며, 결과에 맞는 대화로 이어집니다.
- 삼각형·사각형·육각형 조명을 고르면 그 도형을 목표로 이동과 회전을 반복합니다. 완성한 모양은 후속 대사와 엔딩에 남습니다.

| 차시 | 주요 개념 | 목차에서 열 수 있는 확장 |
|---|---|---|
| 1. 첫 메시지 | 입력·처리·출력, 변수의 값 교체, 사건 | 프로그래밍 세 용어와 표현 비교, 최신 대답, 방향키 지도 |
| 2. 너랑 가는 길 | 비교, AND·OR·NOT, 조건에 따른 경로, 중첩 선택 | 평균·괄호·몫과 나머지, AND·OR·NOT 추가 실험 |
| 3. 마지막 불이 켜지면 | 횟수 반복, 다각형과 회전각, 조건 반복 | 복사와 반복 비교, 계속 반복, 변수로 세기 |

한 차시에 한 챕터를 투사해 개념 수업을 진행한 뒤, 기존 수업 사이트에서 복습·교사 시연·실습을 이어 갑니다. 학급 의견을 듣고 교사가 하나의 선택을 실행하는 방식입니다. 챕터 종료 후 다음 차시로 자동 이동하지 않습니다.

이야기를 한 번에 즐길 때는 1·2챕터 정리 화면 하단의 **축제날로 이어가기 / 점등식으로 이어가기**를 누르세요. 수업에서는 같은 정리 화면에서 멈추고 복습·실습으로 전환할 수 있습니다.

개념 수업은 10~15분을 목표로 설계했으며 실제 학급의 소요 시간은 측정하지 않았습니다. **기본 진행은 차시마다 중심 활동 3개**이며, 확장 활동은 목차에서 따로 엽니다. **설정 → 간결한 대화로 진행**을 켜면 도입·후속 대사를 줄입니다. 교사 메모의 발문과 핵심 진행 안내를 참고하세요.

## 주요 조작

- **하단의 다음 버튼:** 대사 계속, 활동 결과 확인 후 대화 복귀, 다음 장면 이동을 현재 단계에 맞게 수행합니다. 대화 진행 버튼은 하단 하나로 통일했습니다.
- **이야기 속 말투:** 같은 활동으로 이어져도 하루가 선택한 말투를 받아 줍니다. 간결한 대화에서는 활동의 실제 결과를 우선해 말투 반응을 생략합니다.
- **이야기 선택:** 행동의 목표나 보낼 말을 고릅니다. 오른쪽의 **실행 전, 함께 예상하기**는 실행 결과에 대한 예상입니다. 질문과 두 답을 보고 의견을 모은 뒤 실행하세요. 실행하면 같은 자리에 우리의 예상과 실행 결과가 나타나고, 입력과 규칙은 왼쪽에 그대로 남습니다. 작은 화면에서는 예상과 결과가 활동 아래에 표시됩니다.
- **대화로 돌아가기:** 현재 입력으로 실행한 유효한 결과가 있을 때 켜집니다. 이때 결과를 이야기로 확정합니다.
- **선택 다시 보기:** 활동 위의 선택을 다시 고릅니다. 아직 확정하지 않은 실행은 초기화됩니다.
- **이전:** 이전 장면의 첫 단계로 이동합니다. **목차**에서는 모든 장면을 바로 열 수 있습니다.
- **장면 초기화:** 현재 대화·활동을 처음부터 다시 합니다. 이미 확정한 다른 장면의 이야기 결과까지 지우지는 않습니다.
- **교사 메모:** 발문, 예상 답과 결과, 오개념, 핵심 경로를 보여 줍니다.
- **남학생·여학생:** 하루의 외형을 바꿉니다. 학습 내용은 같습니다.

오른쪽 방향키는 현재 단계의 다음 동작, 왼쪽 방향키는 이전 장면으로 이동합니다. 스페이스는 대화를 진행하며, 버튼에 초점이 있으면 그 버튼을 누릅니다. 입력란·선택 상자·지도·열린 대화상자에서는 발표 단축키가 작동하지 않습니다. 지도는 체험 시작 후 방향키로 이동하고, Tab이나 체험 끝내기로 나갑니다.

입력이나 규칙을 바꾸면 이전 결과가 무효화되어 다시 실행해야 합니다. 예측을 골랐다면 결과와 함께 남겨 비교합니다. 실행 후에는 예측을 잠그고 새 실험 때 다시 고릅니다.

반복과 도형은 **명령 한 줄씩** 실행할 수 있습니다. 도형의 이동·회전은 각각 한 단계입니다. 조명의 켜짐·꺼짐과 완료 횟수 ✓를 구분해서 보여 주세요. 목차·메모·설정을 열면 자동 실행이 잠시 멈추고 닫으면 이어집니다. 전체 실행은 명령마다 0.4초 간격으로 이어집니다. 운영체제의 동작 줄이기 설정에서는 0.7초 간격으로 진행하며 전구의 밝기를 고정하고 명령 강조·상태 문구·완료 횟수로 과정을 보여 줍니다. 일시 정지 뒤 실행하면 다음 명령부터 이어지고, 완료 후 다시 실행하면 처음부터 시작합니다.

작은 화면에서는 내용 영역을 스크롤할 수 있습니다. 발표에는 가로 화면을 권합니다.

## 사이트 실습과 저장

**설정 → 복습·실습 사이트 주소**에 수업 사이트를 입력하면 정리 장면에서 새 탭으로 엽니다. 비워 두면 기존 사이트 탭으로 전환하도록 안내합니다.

브라우저가 저장을 허용하면 이름·캐릭터·위치·설정과 확정한 약속·경품·도형을 기기에 기억합니다. 다시 열 때는 타이틀에서 **저장한 장면 다시 열기**를 선택합니다. 해당 장면의 처음부터 다시 열며, 실험 실행 중간 상태와 타이머는 저장하지 않습니다.

다른 챕터에 직접 들어가면 이전에 확정한 결과 또는 차시 기본값으로 진행합니다. 저장이 차단되어도 세 챕터를 사용할 수 있습니다. 새 학급에서 시작할 때는 **이 기기의 기억 지우기**를 쓰세요. 설정 적용이나 이후 진행부터는 새 기록을 만듭니다. 실제 학생 이름을 입력할 필요는 없습니다.

## 확인 범위

세 도형, 두 답장, 두 부스, 세 경품 결과의 활동·후속 대화 연결과 27개 장면을 브라우저에서 점검했습니다. 코드와 움직임, 입력 변경 후 결과 무효화, 모달 중 일시정지, 장면 이동 후 타이머 정리, 저장 복원·저장소 차단, 작은 화면도 확인했습니다. 검증 기록은 `제작-검수-기록.md`를 참고하세요.

실제 학교 프로젝터에서의 가독성, 학생의 흥미와 진행 시간은 현장 확인이 필요합니다. HTML은 약 15MB이며 배경음·음성·외부 서버를 사용하지 않습니다.

## 대화와 캐릭터

대화는 하루의 말, 내 말, 내 생각, 축제앱 알림을 이름표·위치·색으로 구별합니다. 처음 받은 연락은 축제앱의 채팅이며, 초대장 만들기는 같은 앱의 별도 기능입니다. 초대장 이름을 새로 입력해 만들면 이야기 속 내 이름·이름표·설정에도 즉시 반영됩니다.

점등식은 하루가 참여하는 축제 준비팀의 마지막 행사입니다. 전날 약속과 부스 대화에서 미리 소개한 뒤, 마지막 챕터에서 조명의 점멸·배치도·디지털 카드를 개념 활동으로 연결합니다. 캐릭터는 같은 의상과 작은 배지를 유지하면서 19~20세 청년을 참고한 얼굴·전체 비율로 다듬었습니다.

하루는 미소·수줍음·환한 웃음·놀람·고민·장난기의 6표정을 사용합니다. 내 말이나 생각을 읽는 동안에는 직전 하루의 표정을 유지합니다. 첫 초대 수락과 마지막 약속은 플레이어가 답하며, 축제앱의 개인 도착 메시지와 선택한 조명 모양이 엔딩에 이어집니다.


## 수정과 검증

저장소 루트에서 Node.js 20 이상으로 실행합니다. 빌드와 단위 검사에는 패키지 설치가 필요하지 않습니다.

```powershell
node teaching-materials/festival-romance/build.cjs
node --test teaching-materials/festival-romance/tests/*.test.cjs
```

`src/chapters/ch1.cjs`~`ch3.cjs`는 대본·선택·교사 메모, `src/experiments.js`는 활동, `src/models.js`는 개념 계산, `src/state.js`는 이름·책갈피·응답 결합, `src/styles.css`는 화면입니다. `assets/`의 배경 3개와 v6 캐릭터 2개(1536×2048, 3열×2행), 축제앱 휴대폰 그림을 빌드 시 HTML에 넣습니다. 수정 후 dist와 public의 HTML을 다시 생성해 함께 커밋합니다.

브라우저 검사는 루트 의존성의 `@playwright/test`와 설치된 Chrome을 사용합니다. 루트 `npm ci`가 이미 된 PC에서:

```powershell
node teaching-materials/festival-romance/qa/browser.cjs
node teaching-materials/festival-romance/qa/playback-app.cjs
```

Chrome 경로가 다르면 `FESTIVAL_BROWSER` 환경변수로 실행 파일을 지정합니다. 검사의 캡처·결과는 Git 제외 `qa-results/`에 생성합니다. 이 검사는 독립 file URL과 자체 임시 브라우저만 사용합니다. 자동 실행·일시 정지·앱 화면 검사는 제어 시계로 각 명령을 따로 확인합니다. 최종 확인 결과는 `qa/verified-report.json`, `qa/verified-playback-app-report.json`과 검수 기록을 참고하세요. 다음 작업 문맥은 [HANDOFF.md](HANDOFF.md)에 있습니다.

앱 알림과 하루와의 채팅은 전용 휴대폰 그림·축제앱 머리글·파란 메시지 틀로 표시합니다. 현장 대화와 내 생각은 기존 대화 틀을 사용합니다. 초대장·약속 관리·답장·디지털 카드 활동에도 앱 기능 이름을 표시합니다. 문구는 이미지에 굽지 않고 HTML로 표시합니다.
