# 강사님 안내서

이 사이트를 처음 쓰는 강사님(`instructor` 계정, 2학년 10반·11반)께 보내는 사용법 안내서입니다. 보낼 파일은 [`CS-Class-강사님-안내서.pdf`](CS-Class-강사님-안내서.pdf)이고, 원본은 [`guide.html`](guide.html)입니다. 같은 PDF 안에 **1부 사이트 안내(1~2쪽)**와 **2부 실제 수업 운영(3~7쪽)**을 담았습니다. 실제 화면과 짧은 단계별 안내를 중심으로 첫 입장·학생 활동·순회·저장과 제출·종료 확인을 설명합니다. 지정한 정규 수업의 필수 활동 100%를 지원하는 평가 안내도 포함합니다.

## 다시 만들기

문구만 바꾸면 기존 캡처를 재사용해 3~4단계만 진행합니다. 화면이나 버튼 이름이 바뀌면 캡처와 PDF를 다시 만듭니다. 캡처는 로컬 데모(에뮬레이터)에서만 찍고, 운영 사이트나 실제 학생 정보는 쓰지 않습니다. `capture.mjs`는 로컬 `demo-cs-class` 에뮬레이터 연결을 확인한 뒤 **2학년 10반 수업 설정과 가상 학생 `21001`·`21002`·`21003`의 프로그래밍 데모 기록을 초기화**하고 촬영합니다. 클라우드 데이터는 건드리지 않습니다.

1. `npm run dev:emulator`로 로컬 데모를 켭니다.
2. `node teaching-materials/instructor-guide/capture.mjs`로 `images/`의 화면을 다시 찍습니다.
3. `guide.html`의 문구를 맞춘 뒤 `node teaching-materials/instructor-guide/build-pdf.mjs`로 PDF를 만듭니다.
4. PDF를 페이지 이미지로 열어 잘림·깨짐이 없는지 확인합니다.
